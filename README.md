# Art Rally

低多边形画面、驾驶物理优先的拉力游戏。M1 已提供可驾驶灰盒车辆与柏油测试场，M2 物理细化进行中。

## 开发环境

- Godot **4.7.2 标准版**，使用 GDScript，无需 .NET、Node.js 或额外车辆插件。
- 3D 物理使用内置 Jolt 后端，固定 **120 Hz**，开启物理插值。
- Forward+ 渲染，macOS 使用 Metal；桌面优先。
- 世界单位为米、千克、秒，重力为 9.81 m/s²。
- 引擎版本记录于 `.godot-version`，开发脚本检查精确版本。

macOS 首次安装：`brew install --cask godot`。Homebrew 跟随新版发布，不保证日后仍安装本项目锁定的版本；若版本不同，请安装官方对应版本，并通过 `GODOT_BIN` 指定可执行文件。不要为迁就本项目降级其他项目正在使用的引擎。

## 常用命令

在项目根目录执行：

```bash
./scripts/dev.sh doctor  # 查看引擎路径、版本和架构
./scripts/dev.sh editor  # 打开 Godot 项目编辑器
./scripts/dev.sh run     # 启动环境验证场景
./scripts/dev.sh check   # 无窗口导入、脚本解析和物理冒烟测试
```

编辑器中按 **F6** 运行当前场景，按 **F5** 运行驾驶测试场。测试场包含直道、25 m 定圆、蛇形标记、减速带、坡道和连续起伏。原环境验证场景继续保留，自动检查不依赖主场景入口。

`check` 验证环境、输入适配、轮胎模型、车辆悬架/加速/制动/倒车/转向及测试场；日志存入忽略版本控制的 `logs/`。真实手柄连接与主观驾驶质感需人工验收。

## 输入预设

键盘默认标准辅助；F2 切换轻辅助。Q 连按两次可从一挡经空挡进入倒挡，换向必须停车，S 始终为制动。

| 操作 | 键盘 | 标准手柄映射 |
| --- | --- | --- |
| 油门 / 制动 | W / S | RT / LT |
| 转向 | A / D | 左摇杆横轴 |
| 手刹 | Space | A / 底部面键 |
| 升挡 / 降挡 | E / Q | RB / LB |
| 重置车辆 | R | Y / 顶部面键 |
| 切换镜头 | C | X / 左侧面键 |
| 切换遥测 | T | 未预设 |

不同品牌手柄的按键标签不同，最终需使用实际设备验证。

Esc 暂停，Enter 或手柄 Start 明确恢复；失焦和活动手柄断开也会暂停。F8 暂停并导出最近最多 120 秒遥测至 `user://telemetry/`，同时保存引擎与参数信息。T 切换四轮信息和接触力向量；C 切换跟车/引擎盖视角。界面是开发 HUD，正式中文菜单安排在 M5。

## 项目结构

```text
project.godot              引擎、渲染、物理、输入与碰撞层配置
scenes/dev/               环境验证与未来的测试场场景
scripts/dev/              验证场景逻辑
scripts/dev.sh            统一开发入口
tests/                    自动测试
assets/                   未来的模型、材质、纹理和音频
resources/                未来的车辆与路面参数资源
docs/PROJECT_PLAN.zh-CN.md 完整策划案
```

`.godot/` 是可以重新生成的本地缓存，不进入版本控制。GDScript 的 `.uid` 文件需要保留并提交，以保持资源引用稳定。

## 当前不需要安装

不需要建模 MCP、Blender、C# 工具链或第三方车辆插件。初期场景和车辆可通过基础网格与程序化生成实现。导出模板仅在需要打包独立应用时安装，应与 `.godot-version` 中的引擎版本完全一致。
