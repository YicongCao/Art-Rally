驾驶与实际速度

120 Hz 原厂车辆物理，60 Hz 姿态与遥测采样。R200 救车配置只存在于录制进程：ABS 开启，ESP 与牵引力控制关闭；无手刹、无镜内复位。首段素材保留起步预热，电影时间轴从行驶片段切入。弯前真实制动会短暂低于分镜巡航目标，例如侧拍最低 55.6 km/h；没有通过加速播放补偿。

稳定性、事件与流程

专项测试 91 项通过，既有相机、幽灵存档、回放相册、检查点、输入与电影转场相关回归共 149 项通过。侧拍、救车与引擎盖均检查 30 / 60 / 120 FPS 采样与原生渲染；镜头位置和旋转连续，固定拍摄侧。全场景车身包络扫描未发现景物碰撞。驯鹿横穿、河桥关系和直升机同框通过逐帧原生画面检查，至少连续 2 秒可辨。

空格 / Esc / 手柄 Start 暂停继续；暂停菜单提供继续、重播、返回。模拟键盘与手柄输入通过；未将模拟验证声称为实体手柄验证。已检查 1280×720、1920×1080 的暂停和结束页。玩家档案、成绩、解锁与设置未改变。

MovieWriter 的固定帧率用于检查帧序列和时间一致性，不代表所有设备都能实时运行至 120 FPS。正式导出包已从独立空目录读取检查，分镜清单和七段录制均完整打包。

实现边界

未修改普通幽灵格式与玩家存档格式。Demo 扩展遥测与 manifest 放在 resources/showcase；实时渲染使用七份已录制素材，安装包不依赖此文档中的 MP4。原始物理录制使用道路碰撞世界，交付片段另外经过完整场景碰撞扫描。各镜头都是精选片段，跨镜头的路程并非一条连续比赛记录。

影片中的速度为真实物理速度，镜头切换也包含素材切换。15–25° 是救车峰值目标，实际峰值 15.39°；没有把 12 秒整镜描述成持续大角度漂移。
