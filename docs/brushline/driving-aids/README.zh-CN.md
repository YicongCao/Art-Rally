# 涡流风标、落石滚落与驾驶辅助

2026-10-21 · Godot 4.7.2 / Blender 5.2.2 LTS / Apple M5

本轮按 [物理评审](../scene-refresh/PHYSICS_REVIEW.zh-CN.md) 的顺序处理阻力、路面、配重、制动和电子辅助。保留轮胎接触斑、载荷敏感性和组合滑移模型；没有给车身额外添加帮助转弯的力矩。

## 实现

- **阻力与土路：** 车辆显式替换全局线性／角阻尼，保留空气阻力、轮胎滚阻和接触耗散。正式赛道的土路按水深从压实干土（摩擦系数缩放 .82、附加滚阻 .012）过渡到湿土（.74 / .025）和软泥（.64 / .060）。水深是游戏中的湿润代理，不是土壤力学模型。测试场直接指定 Mud 仍表示原有软泥，可用于极端低抓地对照。
- **三车标定：** F160 / R200 / A240 静态前轴目标约 60% / 52% / 56%，前制动比例 .62 / .59 / .61。保留载荷转移与原有轮胎曲线、后轴防倾杆差异；移除生产路径中的固定轮胎容量制动钳制，让制动踏板先提出真实扭矩请求，再由 ABS 调节。
- **ABS：** 每轮独立监测纵向滑移，按对应路面与轮胎刚度确定目标，通过释放／恢复制动压力闭环控制。低于 2 m/s 保留完整停车制动力，2–4 m/s 平滑衔接；手刹独立，不被 ABS 取消。开关默认开启。
- **TC：** 所有路面均可使用，提供关闭／运动／完整，默认完整。负载加权驱动轮滑移经过滤波、滞回与限速后调节发动机请求。修复低速 TC 与离合反复接合的问题：在爬行阶段保留起步扭矩，随着车速连续减弱，不再使用 2400 RPM 的突然放行。没有伪造升挡。
- **ESP：** 提供关闭／运动／完整，默认完整。比较实际横摆、车身侧滑与抓地限制下的目标横摆，使用单轮制动及发动机请求修正。运动模式留出约 14° 侧滑窗口，完整模式约 8°；手刹、倒车、低速和不足三个轮胎接地时不主动稳定姿态。仍需玩家控制速度和反打，不保证任何过快入弯都能转过来。
- **界面：** 仪表盘底部固定三个 ABS / TC / ESP 矢量灯位，淡色待命、橙色介入、斜线关闭。介入显示至少约 160 ms，避免高频压力调节使灯看不清。设置新增独立“电子辅助”分类及矢量图标；移除自动驾驶下拉框，F10 开发快捷键保留。
- **遥测：** CSV 追加辅助开关、实际介入、TC 缩放、目标横摆、侧滑角，以及四轮 ABS 压力、ESP 制动力矩、请求／实际制动力矩。既有列顺序保留，元数据包含新土路参数。

## 测量结果

重刹转向对照：初速 24 m/s、转向输入 .18、制动 .95、记录 1.25 秒。三车前轮平均绝对滑移由无辅助的 .76／.96／.82 降至 .064／.065／.062；转过角度由 18.1°／20.2°／18.9° 提升至 24.6°／31.6°／26.4°。相同小幅反打与油门能够收住姿态。ABS 为转向保留摩擦预算，不能据此声称所有路面的刹车距离都缩短。

后驱车 24 m/s、初始横摆 .8 rad/s、无玩家救车的三秒扰动对照：关闭 ESP 的最大侧滑约 71.8°，运动约 28.4°，完整约 13.2°；完整模式结束时约 1.2°。运动模式保留更明显的车尾活动。

F160 干土十二秒全油门对照：TC 运动将平均驱动轮滑移从 .90 降至 .23，正常升到四挡。湿土、深泥分别测试；深泥仍明显更慢。三车 10% 砂石／软泥上坡均验证持续加速、升挡且没有持续一挡断油空转。以上为受控测试工况，不代表所有赛段的实际速度。
