# Art Rally「套色拉力」画面改造计划

用户批准于 2026-10-19。视觉基准：`art-direction/anime-2026-10-19/C-screenprint-anime.png`。

## 1. 目标与美术规范

改造三辆赛车、三条赛道及全部玩家界面，形成复古拉力海报的整体风格。

- 精选重点资产精修：Blender 制作赛车、近景建筑和重要道具；植被、普通岩石和远景使用改良程序化资产。
- 驾驶克制、菜单鲜明：驾驶以套色、形体和明暗块体现印刷感；纸纹、网点、错版和轮胎印主要用于菜单、加载及成绩页。
- 三车重新设计：重设计外形和涂装，保留车型 ID、驱动方式、号码、动力档及物理尺寸。
- 赛车采用近黑墨线、三级明暗和少量整块高光。环境、人物、动物、直升机、医疗车辆无描边。
- 基础色采用墨黑、暖白、石油青、芥黄、砖红和深紫；三赛道独立配色。
- 驾驶不叠加全屏纸纹或噪点；表面纹理随距离减弱，避免高速闪烁。
- 保留接触阴影、空气透视、湿润反馈及道路、障碍物、路书可读性。
- UI 使用现有 ART RALLY 字体体系、矢量图标、短文案、持久选中态；执行 art-rally-ui 技能。
- 改造前记录同机位旧版截图及性能基线；短样本不能代替完整跑段性能验收。

## 2. Blender 资产与车辆制作

本机 Blender 5.2.2 LTS。先检查 MCP，可用时交互建模；不可用时采用本机 Blender Python。两者交付相同源文件和资产。

- `.blend` 是权威源文件，GLB 是游戏交付；独立导出流程不得重新生成覆盖手工精修成果。
- 旧生成脚本仅维护旧版模型。统一米制、原点、轴向、应用变换、材质命名；导出检查法线、纹理、节点和尺寸。
- 分离外观、描边代理及功能挂点；轮系继续由悬架、转向和旋转逻辑驱动。
- 显式灯具、车牌、尾灯拖尾与镜头挂点，避免靠尺寸推算。
- 每车近景车身约 4 万三角面上限，四轮约 1.2 万上限，三档细节层级，车身纹理最高 2K；按实测压缩。

### 三辆原创赛车

**F160／16 号：轻巧楔形掀背。** 短车头、高座舱、近直立尾门、圆角矩形灯、小车顶扰流板；石油青主体、暖白车顶和斜切侧面号码区、少量芥黄线；紧凑轮拱、白色五辐轮毂。

**R200／27 号：长车头溜背轿跑。** 低顶、后移座舱、长盖、明显后翼子板与鸭尾；砖红主体、暖白偏置纵条、墨黑下侧围；双圆前灯、细横尾灯、白色五辐轮毂。

**A240／44 号：方正宽体四门。** 方正座舱、外扩轮拱、宽肩、进气口、高位尾翼；深紫主体、芥黄肩线和尾翼端板、暖白号码区；矩形组合灯、宽横尾灯、白色五辐轮毂。

精修车窗、门缝、灯罩、轮毂、AT 胎、防滚架和可见驾驶舱，不制作不可见发动机舱或复杂内饰。保留物理包络，原创车徽。

### 重点场景资产

Blender 精修木屋、灯塔、桥梁模块、直升机及记者／摄像机、医疗保障车辆、帆船和起终点气球拱门。完善近景轮廓、连接关系和材质分区。

普通观众、动物、树草、圆木、岩石和山体保留生成与动画系统，调整形体、材质和细节密度，不全库重建。

## 3. 渲染、赛道与 UI 接入

### 渲染与接口

共享视觉样式资源管理赛道配色、阴影色阶、印刷纹理和墨线；UI 配套主题管理颜色、字体和控件状态。车辆定义增加外观资源引用及外观版本，含车身、轮系、描边和挂点；不改变机械版本和成绩／幽灵兼容键。

- 玩家、选车预览、实体回放和幽灵统一外观入口。
- 专用代理反向外壳描边、平滑外扩方向；1080p 近景约 2px，远景减弱。门缝、灯组、轮拱采用受控线条，不按三角面描边。
- 玻璃整块反射、克制高光；保留刹车灯、车牌、轮胎形变、红色拖尾。
- 幽灵材质及描边一并半透明、近距离淡出；实体回放完整材质。
- 环境柔化色阶、低频色块，保留路面类型与积水，不全屏描边。

### 三赛道

- 松岭：芥黄草坡、砖红树冠、石油青松林、暖白／桃橙天。成组树冠与山体明暗，强化木屋、山体拱门和坡顶。
- 海岸：暖白岩壁、青蓝海面、金滩，少量砖红／芥黄。成组海面反光，保留双向旋转灯塔、帆船与终点观景台。
- 高地：深青针叶林、蓝紫山壁、浅黄草甸、远处薄雾。强化贴山临崖，保留安全落石和预警，近处视野清晰。
- 地表以磨损色块及局部细节替代碎噪点；柏油、砂石、泥土、积水各自可辨。扬尘、水花、轮胎印、碎石统一形色。
- 碰撞与视觉先分离：保留既有地标碰撞代理，不从新外观自动生成碰撞；路线、路宽、桥高、路面、检查点及恢复点兼容。

### 完整 UI

覆盖标题、赛道、车辆、加载、HUD、暂停设置、成绩、回放、图库、成绩册、车牌和指南。

- 大标题、套色海报、轮胎印；主按钮顺序：计时挑战、自由练习、设置。教学继续隐藏。
- 菜单哑光印刷色块；驾驶 HUD 轻透明底、数字干净。
- 三种地貌卡片分别重绘，显示路面比例、长度、奖牌。
- 卡片内部动力选择显示实际 PS，勾选／填色／边框共同选中态。
- 计时／速度统一字体；车牌输入／预览／车尾同字体链和中文回退。
- 左小返回、右大确认、手柄可见焦点。
- 保留快速侧滑、对角线布旗、回菜单黑屏时序；不增加持续晃动与频闪。
- 更新回放、图库、加载实机预览，概念图不充当游戏截图。

## 4. 阶段与预算

1 人日约 8 小时有效工作；60～85 人日含约 20% 余量，单人每周五日约 12～17 周。

1. 样片和管线 8～10：F160、250m 松岭、材质、标题、HUD，实机图／驾驶录像／性能。
2. 三车和统一接入 10～14：模型、涂装、轮系、挂点、所有使用场景。
3. 重点资产和三赛道 12～18：Blender 资产、环境库、独立配色与逐段修整。
4. 全 UI 和动态效果 10～14：其余界面、预览和动态世界。
5. 验收收尾 10～15：性能、兼容、平台包、文档和来源。

基础 50～71 人日，样片计入预算；运动／性能未通过先修共同管线，再批量扩展。

## 5. 验收与交付

- Blender 可打开，GLB 独立导入；尺寸轴向挂点材质 LOD 正确；灰度／追尾／远景三车可辨。
- 720p、1080p、宽屏：墨线无裂缝、黑团和闪烁；环境无描边；道路危险和路书可读。
- 高低速、转向、悬架、逆光、雾、积水、追尾／驾驶舱／回放／摄影检查；轮胎灯具拖尾对齐。
- 比较路线／路面／碰撞；旧成绩、解锁、设置、幽灵可读，不改挑战版本。
- 现有解析和功能测试；27 个赛道／车型／动力组合自动驾驶、9 个基础组合完整视觉巡查。
- 实体键鼠／手柄确认返回和焦点，长车牌、锁定档、奖牌、回放设置。
- Apple M5 1080p60 目标：完整三赛段平均／P95／P99，对照旧版；切场景十次无持续资源增长。
- 导出 macOS／Windows，只有对应实机通过才标记验收完成。
- 保存源模型、资产、规范、截图、测试、来源；按阶段验证提交推送 origin，不包含无关修改；版本及正式发布另定。
