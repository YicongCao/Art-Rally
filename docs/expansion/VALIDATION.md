## 同机性能对照

原生 Metal / Forward+、1920×1080，相同画质和固定 60 FPS 模拟步长；每次预热 180 帧、采集 600 帧。海岸 A240 基线与扩展版本交替运行三次，另测赤岩 P7，采样时无矩阵测试并行。

- 海岸基线三次中位数：59.97 FPS，帧时间 P95 17.58 ms。
- 海岸扩展三次中位数：59.97 FPS，帧时间 P95 17.43 ms。
- 赤岩 P7 单次：59.97 FPS，帧时间 P95 17.29 ms，P99 19.30 ms。
- 首次基线存在 123.5 ms 长帧，原始数据完整保留，未从统计中删除。

这些是受当前运行环境约 60 FPS 限制的短样本，只说明所测片段未见持续退化，不能证明全赛道最低帧率、GPU 极限吞吐或长时间稳定性。[全部采样](validation/performance.json)

## 验证方法与边界

测试采用批量运行，初跑失败修复后针对受影响套件复跑；没有宣称一次完整 `dev.sh check` 从头到尾通过。旧测试的三赛道/三车、固定六挡、沙漠必须有树与河流等假设已更新；原车参数及原挑战目标仍受保护。完整日志在忽略目录 `logs/expansion/`，可复核摘要保存在 [validation](validation/README.md)。

新增挑战目标仍标记为未进行真人难度标定。实体手柄、长时间人工试驾以及各车驾驶性格的真人确认尚未完成；模拟输入检查不能替代它们。P7 采用用户确认的四驱版本，银色为暂定配色；质量、轮距等未确认数据标明工程估计，造型属于风格化模型首版，待用户检查。

HTML 预览的本地引用与 JavaScript 语法已检查。内置浏览器安全策略拒绝 `file://` 打开，因此未完成浏览器交互验收；没有改用本地服务器绕过该限制。原生游戏截图与 GUI 测试已独立完成。
