# 首个完整试玩版实施记录

范围以 [实施计划](FIRST_PLAYABLE_PLAN.zh-CN.md) 为准。当前是可玩开发候选版，不能将下面的未验收项标记为已完成。

## 已实现

- 三条固定路线、三车定义与三档动力的 27 个独立版本化挑战；路面、宽度、浅水、坡顶、护栏、涵洞、地标及分段由资源定义。
- 主菜单、选关、三维选车、合并赛前信息的分阶段加载、暂停、结果、重试、成绩册、教学、练习、设置、键盘映射、制作名单。
- 正式挑战锁定机械调校；三段成绩、罚时、铜银金奖牌、个人最佳、近期记录。自动驾驶、接管、练习隔离。
- 30 Hz 姿态与车轮轨迹幽灵，含罚时的时间轴、恢复隐藏、近距离淡出、无碰撞播放；版本兼容检查。
- JSON 档案、临时文件替换、有效备份、损坏恢复、可见保存错误；旧设置迁移，原型成绩另行归档。纪录与幽灵一起提交。
- F160 / R200 / A240 原创 Blender 源文件与 GLB、几何分色与号码、不同轮廓、灯组、轮毂、碰撞尺寸与镜头挂点。
- 秋日松岭、晴日海岸、晨雾高地的环境配色、地貌、植被与地标；菜单使用原创程序绘制山景。
- 原创离线音源：三车五层发动机、路面反馈、换挡/制动/碰撞、三环境声与空间声源、路书/界面/奖牌/纪录提示、菜单音乐；独立混音、输出设备、试听和静音保存。
- macOS / Windows 导出流程、随包操作说明、素材与引擎许可、ZIP 与 SHA-256。

## 0.3.0 候选版增量

- 主菜单顺序：开始计时挑战、自由练习、设置。
- 标准版金牌 → 全车系 +50%，+50% 版金牌 → 全车系 +100%；选车与成绩册手动切档，各档纪录和幽灵隔离。
- 旧金牌保留解锁资格；新增里程碑和成绩/幽灵事务性保存，失败不解锁。
- 三赛道各 10 组观众，1.2 米连续路肩，草地抓地和滚阻调整，规则更新为 time-trial-2。
- 正常画质树木近景 234 米、远景 468 米；草、灌木、岩石等显示距离同步增加 30%，树木近远景渐变。
- 当前增量验证及截图见 [0.3.0 候选版记录](V0_3_0_RC.zh-CN.md)。下文旧性能和九组合记录为历史基线。

## 已验证（历史基线）

- 完整常规检查：36 组、603 项通过；另有 4 项 Python 奖牌标定测试通过。
- 内容目录 114 项、档案与幽灵 26 项、菜单至比赛流程 10 项包含在常规检查中。
- 九组合虚拟手柄自动驾驶全部完赛、零恢复，27 项通过。自动结果未写入玩家纪录。详细数据见 [验收报告](FIRST_PLAYABLE_VALIDATION.zh-CN.md)。
- 十次切场景：每次返回后均 49 个节点、0 孤立节点、93 个资源；预热后内存仅少量缓存增长，无场景资源累积。3 项通过。
- 实际 CoreAudio 输出总线检测 7 项通过，音乐与提示峰值约 0.099，无削波；静音有效。此项不能代替主观听感验收。
- 三车型和三主题已做实际渲染截图检查；已修复初次菜单背景生命周期与字体轴设置问题。
- Windows 候选包 PE 架构和 ZIP 结构检查通过；不代表 Windows 实机验证。

## 性能与交付

已完成 M5 1080p 三主题全赛段性能基线、松岭远景树木优化与完整复测、最终截图和两个平台导出包。松岭优化后平均 69.2 FPS，帧耗时 P95 为 20.87 ms、P99 为 24.05 ms，仍未达到稳定 60 FPS。macOS 包内驾驶、音频与存档检查通过；Windows 仅验证包结构。详见 [验收报告](FIRST_PLAYABLE_VALIDATION.zh-CN.md)。

## 必须由实际试玩完成的发布门槛

- 九组合真人完整跑段；每组合至少三次熟练无恢复基准，按 105% / 120% / 140% 冻结奖牌与版本。目前奖牌仍是明确标注的暂定值。
- 耳机与扬声器主观试听，确认发动机层衔接、响度、循环和风格达到要求。程序合成声音是当前可玩素材，不冒充真实录音或主观验收通过。
- 真实 Windows 游戏流程与性能、实体手柄连接/断开/操作/震动。
- 新玩家不看说明完成流程的可用性试玩。
- 林地慢帧继续优化并在目标硬件复测稳定 60 FPS。

没有进行上述真人或外部硬件验收，因此不标记为可公开发布。
