# Art Rally 0.3.1 — HUD 修订

包含 0.3.0 的全部试玩内容，并加入最后一轮 HUD 调整：

- 右上角赛段计时与个人最佳时间使用仪表盘时速的同款 Chakra Petch 字体。
- 计时块与下方仪表盘左右边缘对齐、宽度一致；主计时居中，保留罚时与个人最佳。
- 720p／1080p 实机画面检查，长计时 `12:34.567`、罚时、个人最佳可同时显示。

0.3.0 的方格平滑加载动画、交错胎印、突破边框的插画、选中态胎印、白色五辐轮毂、AT 胎、右摇杆环视／R3 回正及增强的路面起伏全部保留。

## 下载与验证

- macOS Universal：解压后运行 `Art Rally.app`。已在 Apple M5 实际启动验证；ad-hoc 签名，未进行 Apple 公证。
- Windows x86_64：完整解压后运行 `Art Rally.exe`。已完成导出、PE 架构与压缩包检查，仍待真实 Windows 运行验证。
- `SHA256SUMS.txt` 提供校验值，`BUILD_INFO.json` 记录源码提交及验证范围。

本次继续作为 Prerelease 公开试玩版发布。原手柄菜单与驾驶已有玩家实体验收；新增右摇杆通过输入和包内摄像机测试。奖牌阈值仍待熟练真人标定。

0.3.0 标签创建后收到本轮 HUD 反馈，因此以新的修订标签交付，未改写已推送的标签。赛道版本仍为 7、车辆标定仍为 fp3，与 0.3.0 的存档与个人幽灵兼容。
