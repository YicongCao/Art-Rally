# Art Rally 0.3.0 — First Playable

三条风景赛道、三种驱动性格的离线计时拉力试玩版。

- 夕照松岭、晴岬海岸、雾杉高地；混合路面、起伏、桥梁、圆木障碍与独立路书。
- F160 / R200 / A240，基础动力为 192 / 240 / 288 PS；金牌逐级解锁 1.5 倍与 2 倍动力，每种规格分别保存成绩。
- 奖牌、三段计时、个人最快幽灵、本地存档、赛后多视角回放和直升机摄影 Gallery。
- 完整驾驶声音、环境声音、独立主题音乐、可选男女声中文领航。
- 加载进度采用深青灰／暖白方格与渐隐尾部，并随真实进度平滑增长，插画前景突破边框，背景叠加交错胎印与泥点；选中按钮保留勾选、填色并增加胎印。
- 全车白色五辐轮毂、带凸起胎块的 AT 胎，菜单预览、驾驶与回放保持一致。
- 手柄右摇杆环视与俯仰，松开保留角度，按 R3 回正；保留原菜单导航与驾驶操作。
- 根据试玩反馈再次增强砂石／泥地起伏：原区段幅度提高 80%，松岭／高地／海岸区段数增加到 14／16／7。柏油、桥面和既有飞坡单独控制。

## 下载与运行

- **macOS Universal**：解压后运行 `Art Rally.app`，支持 Apple Silicon 与 Intel 架构。当前为 ad-hoc 签名，尚无 Apple Developer ID 签名与公证；网络下载后可能出现系统安全提示。
- **Windows x86_64**：完整解压后运行 `Art Rally.exe`。
- 校验文件：`SHA256SUMS.txt`。离线运行，首次进入设置车牌号；操作指南在主菜单第二排，也随安装包提供。

源码启动：在项目目录执行 `./scripts/dev.sh run`，引擎版本 Godot 4.7.2。

## 验证范围与已知限制

九个基础车型／赛道组合已全程自动驾驶回归通过、0 次恢复。

macOS 导出包已在 Apple M5 实际启动，验证主菜单、加载、驾驶、声音输出、本地存档与返回菜单。Windows 包已完成交叉导出、PE 架构及压缩包完整性检查，尚未完成真实 Windows 运行验证，因此本次按 **Prerelease 公开试玩版** 发布。

赛道版本为 7、车辆标定为 fp3。旧成绩和旧幽灵保留在本地存档中，与新标定隔离；已解锁动力规格保留。
