# Art Rally 0.3.0-rc.1

离线计时拉力试玩候选版，含三条赛道、三辆原创赛车与三档动力，共 27 个独立计时挑战。

- 标准版金牌解锁全车系 +50% 动力，+50% 版金牌解锁全车系 +100%；选车时手动切换，各档成绩与幽灵独立保存。
- 主菜单顺序调整为开始计时挑战、自由练习、设置。
- 选车后直接加载并发车；加载页只显示赛道、车辆、动力、长度、奖牌目标和进度。
- 每条赛道观众增加至 10 组；植被显示距离增加 30%，树木远近景渐变切换。
- 增加连续路肩，改善草地抓地与减速；高动力自动驾驶更平稳。
- 保留车牌个性化、矢量图标、透明驾驶 HUD、三主题光照和离线声音。

旧版有效金牌继续计入动力解锁。物理调整采用新挑战规则，旧成绩与轨迹保留但不混入新纪录。

这是候选试玩版。奖牌目标暂定，尚需真人标定；Windows 包目前只完成交叉导出及结构检查，真实 Windows、实体手柄和主观听音仍待验收。M5 1080p 的短段采样不等于全赛段稳定 60 FPS。

macOS 包为 Universal，使用 ad-hoc 签名，未进行 Apple 公证；Windows 为未签名 x86_64 包。解压后启动 `Art Rally.app` / `Art Rally.exe`，首次启动按提示设置车牌。操作说明与许可证随包提供，校验值见 `SHA256SUMS.txt`。
