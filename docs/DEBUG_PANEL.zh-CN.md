# 实时可视化调试

## 操作

按 **T** 显示/隐藏合并后的遥测与调试面板，默认隐藏，赛段、驾驶测试场、200 米样板均可用。F9 不再切换面板；**F8** 保留原 CSV 导出功能。开关只影响展示，不修改输入、轮胎或传动参数，也不会把正在使用的手柄切换成键盘。

## 数据含义

- 四轮按 FL / FR / RL / RR 排列。接地灯和 DRV / FREE 标记分别读取接触状态和驱动布局；材质、水深、水阻各自读取当前轮胎接触采样，不使用整车平均值。
- Fz 是法向载荷，单位 N；载荷条中点是车重的四分之一。LEN 是悬架实际长度，行程条从全伸长到压缩限位，单位 cm。SLIP 是有符号的纵向滑移率，后面的角度是侧偏角，单位度。
- 每轮摩擦圆显示横向 Fy / 纵向 Fx 的合成力，向上为正 Fx，向右为正 Fy。容量参考和轮胎模型一致，包含载荷敏感度、路面摩擦与涉水抓地修正。GRIP 是当前合成力与容量的比值，不是路面摩擦系数。
- 发动机图表只显示最近 6 秒的绿色净扭矩曲线，纵轴为 Nm，不再重复显示转速曲线或 RPM 刻度。横轴从左侧 -6s 到右侧 NOW，最新采样始终位于右侧，旧数据随驾驶向左移动；上方读数和右端圆点对应最新扭矩采样。转速历史仍保留在右下角的底盘图表。
- 净扭矩包含发动机阻力、怠速调节以及换挡/限转/同步收油的作用，不是简单的满油门曲线值乘踏板输入。Nm 轴包含负值，可直观看到收油后的发动机制动。
- NET kW 是净扭矩乘发动机角速度；CLUTCH Nm 是传到离合器的实际扭矩，可能与净输出不同，因为发动机有转动惯量。GAS 的两个数依次表示踏板命令和实际有效油门。负净扭矩可表示发动机制动。
- G-G 图的红色小球显示平滑后的车身局部速度差分加速度，横向为 LAT、向前为 LONG，单位 g；它不是包含重力项的真实加速度计读数。外圈为 2 g。ROLL / PITCH 是姿态角，YAW 是角速度。
- 底盘区的小历史图保留转速（金色）和车速（绿色），分别按红线转速和 160 km/h 标尺归一化。图形标记超界时裁剪，但实时数值不裁剪。
- 顶栏显示实际车速、挡位、转速、驱动布局、物理 tick、物理频率、渲染 FPS 和车辆物理回调耗时。场景中的绿色/金色箭头分别为载荷和轮胎合力。

## 更新与验证

面板和历史以 20 Hz 更新，历史最多保留 120 个样本；关闭时停止采样和重绘。暂停冻结历史，复位/重新开启清除旧历史并忽略速度突变，选车菜单关闭调试显示。纯读取层不参与驾驶求解，新增发动机字段仅保存求解中已有的中间结果。

`tests/debug_panel_test.gd` 检查实际扭矩/有效油门、单条扭矩时间曲线的右端更新/左移、负扭矩、右下角转速历史保留、四轮独立数据和单位、湿地摩擦圆、驱动轴标记、快捷键不抢手柄、暂停/复位/互斥、历史上限、多分辨率布局，以及两辆同参数车辆在调试开/关时的物理一致性。

完整验证：`./scripts/dev.sh regression`。只更新 README 中间的调试截图：

```bash
godot --path . --max-fps 60 --script tests/readme_capture.gd -- --test-defaults --debug-only
```

截图工具从真实 T 输入打开调试，在泥地水洼内通过物理驾驶到拍摄点；检查四轮状态、非空历史和图形窗口布局。正式截图为 `docs/previews/readme-debug.jpg`，960×540 窗口检查图存入忽略版本控制的 `logs/debug_panel_960.png`。不保存或覆盖玩家设置。

实机检查覆盖 1280×720 与 960×540 两种窗口，截图工具还会检查红色 G 值小球的实际渲染像素，以及扭矩历史和底盘区转速历史的同步。
