# 驱动选择与倒车辅助

- 主赛段启动前选择 FWD、AWD 或 RWD；AWD 是原默认基线，记住上次选择。重跑保留车型，暂停设置中的“更换车辆”会在确认后重开，取消不改变原赛段。
- 三种模式共用质量、重心、轮胎、发动机参数，只改变真正的驱动轴、差速器耦合和发动机连接的轴转速。FWD 不给后轴驱动/限滑转矩，RWD 不给前轴驱动/限滑转矩；RWD 拉手刹时离合器解耦。不是前置/中置/后置发动机质量布局选择。
- 停稳并持续保持有效制动输入 3 秒，HUD 显示倒计时和逐渐缩短的横条，然后通过变速箱安全挂 R。移动/离地不计时，松键立即取消，不受踏板滤波残留影响。
- 倒挡中 S/↓/LT 渐进加速倒车；W/↑/RT 请求前进。若仍在后退，先以服务制动停稳再挂一挡，不能高速瞬间反向。进入前进挡后 S/↓/LT 恢复制动作用。
- 同时踩两踏板不会意外挂入倒挡；暂停、失焦、复位、选车和明确的手动换挡会清理辅助计时。自动降挡的短暂换挡间隔不会反复重启 3 秒计时。
- 自动倒车与自动换挡分别配置。暂停设置可关闭倒车辅助，恢复原手动倒挡操作。

验证：完整回归及原 AWD 的 30/60/120 FPS 回放通过；新增 33 项专项检查覆盖转矩守恒、非驱动轴零转矩、驱动轴转速耦合、三车型物理加速、3 秒时序、取消/暂停、实际倒车及安全回前进。另有 3 项真实窗口检查：选车页冻结物理、Enter 确认不会立即再次暂停、实时倒车横条显示。

`./scripts/dev.sh run` 或 `./scripts/dev.sh stage` 均进入新选车流程。开发测试场/200 米样板保留 AWD 基线，不显示选车页；无窗口回归和 `--test-defaults` 工具绕过前端，使用默认设置。

实机检查：`godot --path . --script tests/drive_choice_render_check.gd --max-fps 60 -- --test-defaults`。截图输出在 `logs/vehicle_choice.png`、`logs/reverse_hold.png`。真实手柄按键/扳机手感仍需硬件试玩。
