# 比赛配乐：贝斯与鼓组推进

2026-10-22；基线 d43fb19；Godot 4.7.2 / CoreAudio。

- 松岭：144 → 156 BPM。车库摇滚的切分吉他，配八分音符贝斯、加强底鼓、军鼓反拍与每四小节短加花。
- 海岸：128 → 140 BPM。保留四拍底鼓，贝斯由反拍四音扩展为八分音符推进，并强调反拍。
- 高地／赤岩：110 → 132 BPM。保留长音和通鼓，加入四拍底鼓、军鼓反拍、踩镲和连续贝斯。

贝斯与鼓组在编曲混音中的占比提高；底鼓击打时短暂压低贝斯和伴奏，让瞬态清楚。比赛曲目的延迟效果只作用于旋律层，低频节奏保持干净。主音乐音量设置及领航时自动压低音乐继续沿用。菜单音频与 MIDI 字节未变；Demo 使用松岭主题，因此同步获得新编曲。

生成器 `scripts/generate_music.py`、三首 MIDI、PCM WAV 与节拍报告已更新。每首仍为 16 小节整拍循环，离线合成，运行时不增加合成或处理开销。
