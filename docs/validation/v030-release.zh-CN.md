# Art Rally 0.3.0 发布验收

2026-10-18，Godot 4.7.2，Apple M5 / Metal Forward+。

## 本轮变更

加载页使用深青灰与暖白方格进度，尾端 26 px 淡出；可视进度平滑追随实际目标，长帧限幅，始终不领先真实进度。插画使用独立前景打破矩形边框，右下角加入两条交错的半透明胎印和泥点。选中按钮／卡片保留对勾、底色与边框，并加入右下角胎印；装饰不接收鼠标与键盘焦点，同步设置时也更新状态。

三车、菜单预览、回放与幽灵统一白色五辐轮圈和 AT 胎。五辐、外圈、螺栓和凹入的制动盘使用几何建模；AT 胎包括四排交错的凸起胎块与胎肩细节。沿用原轮胎形变、轮转和转向节点，未增加轮胎碰撞体或改变其物理半径。

右摇杆支持追尾、车头、驾驶舱的环视与俯仰；采用径向死区，松开保留角度，R3 回正。暂停和断连清理输入；环视不会清掉行驶轴、改变驾驶设备或把自动驾驶判成人工接管。驾驶舱仪表随车身保持位置，不随转头一起旋转。

按玩家反馈增强起伏：原有区段幅度提高 80%，松岭／高地／海岸由 8／9／4 段增加为 14／16／7 段。单侧轮迹超过 5 mm 起伏的非柏油覆盖率约为 21.0%／20.9%／38.8%，该轮迹峰值约 8.18／8.18／11.42 cm。海岸峰值包含相邻区段叠加；柏油、桥面、引道和既有飞坡继续单独控制。赛道版本更新为 7，旧纪录与幽灵保留但隔离。

## 验证结果

共 458 项断言通过，见 [检查清单](v030-checks.json)。三车 × 三赛道的九个基础组合全部完整完赛、0 次恢复，不写入玩家成绩；见 [驾驶数据](v030-driving-matrix.json)。并行跑段中的 CPU 数据不作为独立性能验收结果。

加载动画测试覆盖无跳变、最终追上实际进度和不超前；右摇杆通过 Viewport 事件、暂停／断连、三种镜头与回正检查；菜单手柄操作回归 35 项通过。胎纹与轮毂只改变视觉，轮胎接触和形变回归通过。

原生 720p／1080p 截图检查三种赛道插画、交错胎印、选中态、进度尾端与文字。拍摄使用独立档案；静音仅用于截图进程。

macOS Universal 导出包在 Apple M5 实际启动，通过版本、菜单、27 个内容定义、加载、驾驶、真实音频输出、存档、返回菜单、包内右摇杆与 R3 检查。运行退出时先停止音频并等待音频线程清理；最终 smoke 日志无错误或泄漏警告。Universal 二进制包含 x86_64 与 arm64，ad-hoc 签名验证通过。

Windows x86_64 已交叉导出，通过 PE 结构、压缩包完整性和关键资源检查；未在真实 Windows 运行。玩家此前已验收原手柄菜单／驾驶操作，本轮新增右摇杆为自动输入及原生摄像机集成验收，不替代新增功能的实体手柄反馈。奖牌目标仍待熟练真人标定。因此 GitHub 以 v0.3.0 Prerelease 公开试玩包发布，不标为 Windows 已实机验收。

构建过程中两个 Godot 导出进程竞争同名临时 project.binary 文件，失败已识别；最终两个平台按顺序重新导出并验证，失败产物未用于发布。
