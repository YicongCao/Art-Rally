# Art Rally 0.4.0 发布记录

2026-10-20，Godot 4.7.2，Apple M5／macOS。

## 本轮变化

- 路书移回顶部居中，保持漫画箭头；小地图检查点序号和米数向右上倾斜、上移 6 px。
- 前驱 GTI 基础动力 220 PS，另外两档 330／440 PS，实际扭矩曲线同比调整。F160 独立标定升级为 fp4，旧成绩保留，旧幽灵与新动力隔离；后驱／四驱和解锁状态保持原样。
- 页面背景独立于横向侧滑的 UI 内容；驾驶、回放时背景随菜单正确隐藏。
- 标题按钮 hover 直接提亮实际绘制的色块，保留键盘／手柄焦点边框。
- 加载页采用标题同源海报背景加深墨色覆盖、暖白文字与橙金点缀；删除百分比数值，保留动画方格进度条和插画。
- 热气球常规侧向距离从 330–650 m 调为 190–380 m，常规高度从 100–230 m 调为 75–150 m，模型放大 35%，保留稀疏分布与防拥挤间距。
- 项目与 macOS／Windows 包版本更新为 0.4.0。

## 自动验证

592 项相关自动检查通过（无头检查加原生窗口交互检查）。覆盖 HUD、内容目录、页面切换、真实 Viewport 鼠标 hover、加载进度、菜单流程、个人存档／幽灵、动力档进阶、选车手柄、车辆外观、回放与车牌。

macOS 导出包自动启动检查输出 `PACKAGE SMOKE PASSED`，检查三赛道／三车／三档资源、菜单发车、实际行驶、右摇杆视角、车牌与回放等。macOS 应用版本为 0.4.0，通过 ad-hoc 签名完整性检查，未进行 Apple 公证。

Windows x86_64 完成交叉导出、PE 架构与 ZIP 完整性检查。两个 ZIP 均通过 SHA-256 回读校验。数据和校验值见 [v040-release.json](v040-release.json)。

按用户要求，本轮不进行人工试玩；没有真实 Windows 实机验收。奖牌目标沿用现有工程目标，尚未经熟练真人基准跑标定。

## 发布内容

- `Art-Rally-macos-universal.zip` 及同名 `.sha256`
- `Art-Rally-windows-x86_64.zip` 及同名 `.sha256`

解压后启动 `Art Rally.app` 或 `Art Rally.exe`。macOS 使用 ad-hoc 签名，首次运行可能受到 Gatekeeper 限制。
