# Art Rally 0.3.0-rc.3

玩家体验、混合路面、赛后回放与沿途影像候选版。

- 动力按钮直接显示 PS，车辆、赛道和动力选择拥有矢量对勾及持久选中态；驾驶状态改为矢量图标。
- 新标题字标、独立操作指南与相册；车牌采用 Chakra Petch 英文／数字及 Noto Sans SC 中文回退。
- 车身擦入气柱范围即可通过检查点，仍保持正向、顺序与高度限制。
- 三条赛道均有混合路面和占比说明，新增磨损、湿润过渡及 2／2／3 处河流窄桥。
- 默认显示兼容的个人最佳幽灵；完赛自动播放本次轨迹，支持电视、航拍、追尾、路旁镜头与沉浸回放。
- 新个人纪录标题增加短纸屑礼花；橙白新闻直升机每场经过四次并拍照，保留最近 64 张航拍。
- 四首原创主题配乐，附可编辑 MIDI 与离线 WAV；修复压缩音轨循环长度。
- 增加随车速变化的尾灯气流拖尾、远处海鸥和热气球，扩大并移近终点海湾帆船。

路线版本 3、规则 time-trial-3。旧成绩及幽灵保留归档，已有动力解锁保留。

验证：48 组、961 项功能检查，7 项 Python 测试，17 项 CoreAudio 链路检查通过；27 组合自动完赛、零恢复。十次场景切换无节点或孤立节点增长。macOS 包启动检查、Windows 包结构检查通过。

M5 1080p 短段采样平均约 60／66／60 FPS，仍有超过 16.7 ms 的帧；未完成全赛段稳定 60 FPS、真人奖牌标定、实体手柄、主观听音或 Windows 实机验收。macOS 使用 ad-hoc 签名、未公证；Windows 为未签名 x86_64 包。此版本保持候选状态。

详细说明与实拍：源码中的 docs/PLAYER_EXPERIENCE_UPDATE.zh-CN.md；验证记录：docs/validation/v0.3.0-rc.3.json。
