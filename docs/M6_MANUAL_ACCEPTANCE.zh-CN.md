## 声音试听

使用默认音量和常用耳机 / 扬声器分别检查：

- [ ] 怠速、加速、高转和换挡中断层次可辨，无持续爆音
- [ ] 收油后负载声不会盖过发动机主体
- [ ] 柏油、砂石、泥地胎噪差异可辨但不过度抢占
- [ ] 入水与离水边界自然，水声不会长时间残留
- [ ] 坡顶落地的冲击声清楚但不刺耳、不连续误触发
- [ ] 暂停立即冻结所有循环声，恢复时无突兀满音量跳变
- [ ] 音量滑条 0 时静音，恢复默认后回到 0.65
