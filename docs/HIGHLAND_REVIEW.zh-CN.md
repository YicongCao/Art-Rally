# 雾杉高地山崖改造复查

## 结论

用户未看到修改的直接原因是运行了旧源码目录，并非 Godot 构建缓存未更新。与此同时，原实现虽然创建了山崖参数和落石节点，但近路地形、地面遮挡、路书合并和画面验收确实没有做完整，不能把“节点测试通过”等同于体验已经生效。

## 已确认的问题与修复

### P1：日常启动目录没有包含山崖提交

- `/Users/cong/Documents/Projects/Art-Rally` 的 `main` 停在 `0625332`，该目录的启动日志更新至 2026-10-18 22:35。
- Codex 工作树在 `codex/autumn-forest-art-direction`，原山崖提交为 `8a71d5f`；当时只推送了功能分支，`origin/main` 也没有包含该提交。
- 两份目录执行同一句 `./scripts/dev.sh run`，实际加载的源码不同。导入资源不会同步 Git 分支。
- 修复：验证后将常用目录和远端 `main` 快进到修复版本；启动脚本同时显示源码绝对路径、提交号和分支，方便确认运行来源。

### P1：新地貌被二次混合压低，且被宽地面带遮挡

- `scripts/presentation/stage_scenery.gd` 先把山崖写入 `far`，再按距路中心 21–110 米混回近路平地。18 米处的新地貌权重仍为零，30 米处的权重也很小。
- `scripts/stage/stage_generator.gd` 的道路网格实际包含左右各 22 米的草地区域；崖侧地形即使下降，也会被这片原地面遮住。
- 修复：在通用地貌混合之后生成山崖；在四段山崖区域，仅裁去路面材质中路肩之外的宽草地带，保留原来的路面和碰撞顶点。
- 高地地形网格细化到 4 米，以减少陡坡三角形跨进路面或植物悬空的风险；坡面采用岩石色调。

### P1：空间查询漏掉最近道路，制造异常地形断层

- 原查询只检查当前 64 米网格周围的 3×3 网格，未保证其中包含真正最近的道路段。跨网格边界时，查询可能突然选择更远的道路，而不是实际最近的道路。
- 在高地 1930 米路段右侧复现：采样位置仅相差约 4 厘米，高度从约 91.9 米跳到约 214.0 米，形成异常岩墙。
- 修复：为每个网格缓存一个保守的道路候选集，保证最近道路及地貌混合所需的相邻道路不会被漏掉；并在道路外混合相邻回头弯的地形影响，保护驾驶走廊。修复后的真正最近道路交界处，同样约 4 厘米的采样间距，高度变化约 4.7 厘米。
- 植被和岩块以最终渲染网格高度落地，陡坡上不再铺满草丛和灌木；岩块先选择最终位置，再采样地面，避免沿曲线偏移后悬空。
- 落石动画也跟随最终网格高度，避免直线插值穿进增强后的山体。

### P2：两处落石预警被圆木预警删除

- `scripts/stage/stage_route.gd` 在逐条加入危险提示时，也过滤了此前已加入的危险提示。430 米和 1910 米处的圆木预警分别删除了附近 450 米和 1930 米处的落石预警。
- 修复：只清理自动生成的普通弯道提示，之后统一加入手工编排的危险提示；验证运行时路书列表和实际会话都能保留五处落石提示。

### P2：原验证没有覆盖最终可见结果

- 原测试核对了配置长度、节点数量和落石终点，未核对最终渲染的路边高差、被遮挡的地形或运行时路书。
- 原截图使用了手工放置的远距离镜头；新截图通过实际物理驾驶和生产追尾镜头取得。
- 新增验证：四段地貌的可见高差、道路未被山体覆盖、全部原道路顶点不变、回头弯边界连续性、落石全轨迹安全性、五处运行时预警。
