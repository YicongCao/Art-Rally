# Brushline Rally 改造实施记录

依据本轮确认的计划：统一品牌与包名、旧档迁移、松岭金牌解锁挑战（练习开放、旧玩家保留已玩赛道），修复落石语音与电线杆，重构暮色高地及真实悬崖，制作画册三格 UI、追尾车辆细节与 Blender 环境资产、磨损路面，新增真实物理玩法演示。

## 交付顺序

1. 基础修复、品牌与存档、赛道解锁。
2. 高地碰撞、暮色车灯、安全落石和海岸色彩。
3. imagegen 画册、品牌与地表素材，Blender 源文件及游戏导入，三格 UI。
4. 演示、回归、性能记录、双平台验证包、同步常用目录。

## 保持的约束

- 新名 Brushline Rally，默认品牌展示牌 BRUSHLINE；用户车牌不改。
- 新存档经校验迁移，原目录保留。高地旧成绩与幽灵归档隔离；其余机械版本不变。
- 高地落石不与赛车碰撞；崖边真正失去支撑，沿用越界恢复罚时。
- 画册使用生成插画而非游戏截图；文字与动态数值由 UI 绘制。驾驶没有全屏纸纹。
- `.blend` 为权威源，GLB 为运行时文件；车有描边、环境无描边。
- 演示采用松岭、后驱基础车、真实物理控制与遥测，不写入玩家成绩。
- 不自动创建正式 Release。真人奖牌标定、真实 Windows 验收不能以自动测试替代。
