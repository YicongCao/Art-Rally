# 明艳动画电影质感：实现判断与首轮实机原型

参考依据：用户提供的「A · GRAPHIC ANIME RALLY」概念图。日期：2026-10-19。

## 判断

这类画面可以在 Godot 的实时三维场景中实现相当接近的视觉语言，但当前结果仍是原型，尚不等同于概念图的高保真还原。概念图同时完成了构图、形体、色彩和局部绘画修饰；插件只能承担部分渲染机制，不能自动补齐这些美术工作。不能用单帧截图证明所有弯道、逆光、驾驶舱与回放镜头都达到同等品质。

建议沿用已完成的三维资产、玩法与外观入口，发展为“动画式场景着色＋车辆墨线＋复古平面 UI”。保留套色拉力的识别色和印刷 UI，增加参考图中鲜明的冷暖关系、光泽与天空层次。

## 各项效果的真正来源

- **油亮枝叶：** 成组叶簇的轮廓、统一过的法线、宽而克制的高光，以及逆光透色共同作用。直接降低粗糙度容易产生湿塑料质感。当前增加了六边叶片、树冠法线偏置、叶面高光和逆光透色；近景叶簇仍有明显程序化折面，需要进一步手工调整树冠与枝条层次。
- **鲜明远山：** 山脊造型、冷紫阴面、暖色受光面与受控空气透视，比饱和度滤镜更重要。当前新增独立山体绘画材质，保留原始几何和碰撞；山脊的形体复杂度仍不及参考图。
- **动画式飘云：** 首轮采用方向空间的原创程序云，合并云团轮廓后统一采样照明，形成暖边、粉色中间层与紫影。它随世界方向保持稳定，不会像近景云网格穿过山体；只有缓慢漂移，暂停时冻结。作为天空背景，它没有近距离体积视差，也不投射移动云影。高保真下一步应加入专门绘制、可编辑的云形和内部色块图层，制作大中小云团及细长卷云的不同组合。
- **赛道：** 保持路面材质、积水、磨损和接触反馈，避免全屏纸纹破坏高速可读性。原始物理路面和比赛兼容键不变。
- **HUD／UI：** 橙色强调、墨黑暖白底色、倾斜 HUD 面板、干净数字区；标题页改为暖纸色与橙黑斜切构图，保留主按钮顺序、中文字体链、矢量图标、选中态和手柄焦点。不是把整张概念海报贴在屏幕上。

## 渲染与插件取舍

Godot 的 [Sky shaders](https://docs.godotengine.org/en/stable/tutorials/shaders/shader_reference/sky_shader.html) 支持自定义天空、辐射图和低分辨率子通道；修改天空参数会使辐射图更新。当前云漂移每半秒更新一次参数，避免无必要的逐帧环境反射重建；复杂云形在半分辨率通道绘制，反射辐射图仅计算稳定的天空大色调。云采用原创解析轮廓，没有体积光线步进、透明云面片排序或外部贴图依赖。

[Spatial shaders](https://docs.godotengine.org/en/stable/tutorials/shaders/shader_reference/spatial_shader.html) 提供自定义光照和 toon 渲染能力，因此叶片的透色、高光与色阶可以直接在项目中维护。环境不加描边，车辆保留专用外壳描边；未引入全屏边缘检测。

调研了 [Stylized Procedural Sky](https://store.godotengine.org/asset/emace-art/stylized-procedural-sky/)：提供卡通云、渐变与色阶控制，最低 Godot 4.7，但采用作者专有许可。本轮没有引入该资产，也没有将商店页面上的效果当作已验证的本项目能力。即使使用此类插件，仍然要制作符合参考图的云形与场景资产。

暂不采用重型实时体积云／统一全屏油画滤镜：前者需要额外性能预算，后者容易使路面、车牌和远处树叶在运动时产生不稳定细节。之后若测试自定义云图层，优先稳定的世界／方向空间纹理、Mip 层级与分层慢速运动。

以上都是 Godot 原生 Metal 渲染，非概念图、非图片后处理。环境观察镜头与驾驶视角分别标注。截图工具使用独立玩家档案并静音测试会话；不修改玩家设置。

实际像素通过 1920×1080 离屏视口检查，避免 macOS 窗口尺寸限制。三赛道分别连续采样 360 帧，记录墙钟 P95/P99；采样包含视口显示开销，且限帧 60。半分辨率优化后有一轮三段 P95 为 17.20～17.37 ms，但补拍加载预览后的复测为 19.29～25.96 ms，P99 最高 41.51 ms；全分辨率云计算曾有一轮 P95 为 28.6～31.3 ms。短样本波动明显，不能由单次较快的结果判定稳定达到 60 FPS，也不能把全部差异归因于云着色器。它只证明代表性短段能运行，**不是完整赛道 60 FPS 验收，也不是与旧版性能等价的证据**。完整同条件旧版性能测量未成功产出有效对照，本轮不宣称该项通过。

## 仍需完成的高保真工作

1. **云形美术生产：** 制作多层云形及内部笔触／色块图层，减少规则轮廓，加入小云与远处细长云带；继续验证镜头旋转、全周接缝与运动稳定性。
2. **重点环境形体：** 树冠需要枝叶疏密层次；山脊需要真实地质走向与更精细的受光面。仅修改着色器无法把现有三角面变成概念图的形体细节。
3. **车辆精修：** 已接入原创 Blender 车辆、挂点、三档 LOD 与描边，但车身面、轮拱、灯罩及装饰细节距离图中精度仍有差距。
4. **统一终验：** 三赛道逐段修整、更多驾驶速度和逆光角度、720p／宽屏运动检查、全程性能与 Windows 实机验证。已有外观管线和样片不等于 60～85 人日整项美术改造已经终验。

本轮没有重发 macOS／Windows 发布包。`screenprint/packages.json` 是本轮动画光感修改之前的验证包记录，不能拿它证明本轮已导出或通过平台验收。

## 复现

从此 checkout 启动可直接看到修改：

```bash
./scripts/dev.sh run
```

生成本轮截图与短段数据：

```bash
/Applications/Godot.app/Contents/MacOS/Godot --path . --max-fps 60 --script res://scripts/dev/anime_direction_capture.gd -- --test-defaults
```
