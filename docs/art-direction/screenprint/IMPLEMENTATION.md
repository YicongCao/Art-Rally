# 套色拉力实现与验证

本轮采用已确定的 C 方向：近黑车辆墨线、三级明暗、独立赛道配色和菜单印刷质感。版本仍为 0.3.1，视觉资源单独标记 `screenprint-1`；没有创建新的正式 Release。

[打开实机前后对照与录像](index.html)

## 实现范围

- 三辆原创 Blender 赛车及三档 LOD，保留 F160／R200／A240、16／27／44 号、驱动方式和物理尺寸。石油青掀背、砖红溜背、深紫宽体分别使用不同侧影、灯组和涂装。
- 可编辑源模型、独立 GLB 导出、AT 胎和白色五辐轮毂、功能挂点、平滑法线描边代理。近景车身约 9,000–10,200 三角面（不含重复描边代理），四轮合计 11,552 三角面。
- 玩家车、选车、回放和幽灵共用外观入口；幽灵描边随车体淡出。车牌、尾灯拖尾和镜头读取新挂点，物理轮系保持原逻辑。
- 木屋、灯塔、直升机及记者、医疗车、帆船、气球拱门和桥柱使用 Blender 资产。桥面继续由原路线匹配生成；灯塔光束、旋翼、记者拍摄、河流与落石等事件保留。
- 三赛道公共材质、树冠、天空、地表和海面调整为更整块的配色；未叠加驾驶全屏噪点或环境轮廓检测。
- 标题、选择、加载、设置、HUD、成绩、回放、图库、成绩册、车牌及操作指南使用配套主题；保留矢量选择态、手柄焦点及原转场时序。驾驶数字区保持干净，菜单加入套色边饰和印刷纹理。加载页使用本版本实际渲染的赛道预览。

## 兼容性证据

改造前基准提交为 `64d7610`。`baseline/` 与 `current/` 保存同机位截图及路线／碰撞快照。

- 三赛道路面资源、车辆机械资源及奖牌配置的 SHA-256 未改变。
- 对全部世界坐标碰撞三角形、原始碰撞体及路线点排序后比较，三条赛道完全相同：松岭 37,120 项、海岸 43,880 项、高地 46,779 项。
- 27 个挑战兼容键相同；视觉版本不进入成绩或幽灵键。
- 实机回放截图使用改造前保存的松岭轨迹，未重算旧轨迹物理。
- 连续切换十次场景：节点始终 61、孤儿节点 0、资源 150；三个主题预热后内存从 194,966,091 到 195,059,775 字节，未出现持续增长。

## 验证说明

专项资产／挂点／兼容性测试 90 项通过；原生窗口方格旗遮罩在 1280×720、1280×800、1680×720 下 27 项通过。键鼠／手柄 GUI 路径自动测试继续通过；模拟手柄不等于实体手柄验收。

- 62 个测试套件累计 1,469 项检查；1,463 项通过，6 项为下述已在旧提交复现的问题。原先不能在 headless 下运行的布旗渲染测试已在原生渲染器单独通过，未当作产品失败计入。
- 三赛道 × 三车型 × 三动力档共 27 次完整自动驾驶跑段全部到达终点、零恢复，且未写入玩家成绩；见 `drive-matrix.json`。并行回归中的物理耗时不作为性能基准。
- 1280×720 与 1680×720 下八个菜单页面分别生成实际像素截图，检查车辆卡片、锁定档位、确认／返回与中英混合 10 字符车牌。宽屏使用 Metal 离屏视口，避免 macOS 限制原生窗口尺寸造成虚假的分辨率记录。
- `showcase.mp4` 是 29.35 秒原生 Godot 录制，三赛道各包含一段实际自动驾驶。脚本验证每段车辆前进至少 20 米，测试会话静音；不是基于静态图的动画，也不用于性能计时。
- Blender 5.2.2 LTS 本地 Python 路径生成和导出；本会话未发现可调用的 Blender MCP。13 个 `.blend` 源文件均由 Blender 打开导出，形成 19 个 GLB。设计色从 sRGB 正确转换到 Blender／GLTF 的线性颜色。

完整测试遇到旧版本已经存在的失败，已在独立的旧提交目录复现：`experience_update_test` 缺少男女 ROCKFALL WAV 两项；`utility_line_test` 电线杆支撑与地面／线缆高度四项。保留这些问题记录，没有把总测试标记为全绿。

`capture-metrics.json` 仅是截图附近 180 帧 CPU process 时间，不能作为完整赛段平均 FPS 或 GPU 性能。完整跑段、导出及性能结果会在验证完成后补在下面。

## 验证包

macOS universal 与 Windows x86-64 验证包已生成，大小及 SHA-256 见 `packages.json`。Mac 导出包在本机真实启动，通过菜单、选车、驾驶加载、五辐轮系、车牌、音频信号、存档读写和返回流程的自动冒烟检查。Windows 通过 PE 架构、嵌入资源和压缩包结构检查，尚未在 Windows 实机运行。音频信号验证也不能代替耳机／扬声器的人工听音。

文件位于项目的 `builds/macos/Art-Rally-macos-universal.zip` 与 `builds/windows/Art-Rally-windows-x86_64.zip`；没有上传或覆盖 GitHub Release。

## 复现入口

```bash
./scripts/dev.sh run
./scripts/dev.sh screenprint-check
./scripts/dev.sh screenprint-capture
./scripts/dev.sh screenprint-export
```

运行命令前进入保存这些改动的工作目录。另一个旧 checkout 不会自动具有这些改动。

源码规范见 [源文件说明](../../../art_source/screenprint/README.md)，完整要求见 [实施计划](../../SCREENPRINT_ART_PLAN.zh-CN.md)。

## 验收边界

这是可运行、可继续编辑的新视觉实现。精修不代表完成了人工美术终验：高速运动的纹理稳定性、九个基础组合全程人工巡查和实体手柄仍需实际验收。Windows 实机及其声音／输入验收不能用 macOS 导出检查替代。未通过的项目不标记为发布就绪。

## 后续参考图与验证状态更新

用户随后提供动画电影风格参考。最新运行效果已经继续调整；本目录的场景截图、视频与验证包是此前套色资产阶段的记录，UI 分辨率截图则在新主题下复查。最新效果、技术调研和未完成项以 [动画质感原型](../anime-prototype/README.zh-CN.md) 为准。

完整旧版／新版 1080p 性能对照未成功产出：早期测试发现原生窗口尺寸不等于声明分辨率，已修复为固定离屏视口；后续完整跑段未结束便中断，未生成有效对照。保留修复后的测试入口，不把短段 CPU 数据或自动驾驶功能回归当作性能验收。当前验证包也不含后续动画质感修改。
