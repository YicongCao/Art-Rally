# 200 PS 动力与自动换挡修正

## 问题原因

旧扭矩曲线峰值折算约 230 kW，约 310 hp / 315 PS，并未限制在期望的 200 匹级别。旧自动挡仅用发动机 RPM 决定升降挡：泥地空转时连续升挡，而持续的高转速又阻止低速降挡。

按现有轮胎半径和齿比，25 km/h 的六挡无滑动转速仅约 696 RPM。6767 RPM / 六挡 / 25 km/h 可以在严重空转时出现，但自动挡不应该把车辆带入这一状态。仪表原本读取真实刚体速度与真实发动机转速，不是显示单位换算错误。

## 当前标定与策略

- 所有 FWD / AWD / RWD 使用同一 200 PS（147.10 kW）净发动机输出曲线，峰值 260 Nm，车重 1250 kg；不改变轮胎抓地、悬架、重心或齿比。
- 功率上限同时约束插值后的扭矩，避免曲线控制点之间超过标称功率。全油门的曲线是净轴端输出；收油仍有内部阻力与发动机制动。
- 升挡要求发动机超过 6800 RPM，当前挡实际车速对应转速超过其 88%，驱动轮滑动率小于 35%，发动机/轴端耦合偏差小于 28%，且未踩明显制动。轮速按真正的驱动轴采集。
- 当前挡实际车速对应转速低于 2600 RPM 时主动降挡，可跳到合适挡位；加油时目标不超过 4200 RPM，收油时采用 3200 RPM 的较温和选挡目标。
- 降挡前同时检查实际车速与传动轴转速，预测转速低于红线的 97% 才执行；否则暂时断开油门动力，让空转消退再降挡。不把发动机转速硬绑到车速。
- 保留 0.16 秒换挡和 0.5 秒自动换挡冷却，跳跃/手刹不触发自动换挡，手动操作优先。悬架接触采样后再做选挡，避免依据上一帧的离地状态判断。
- 主 HUD 增加“驱动轮空转 / 同步降挡”，驾驶舱增加 `WHEELSPIN / SYNC DOWN`；选车界面展示当前资源的额定功率。

这不是完整的 traction control。特别是泥地前驱/后驱满油门仍会空转，需要控制油门；没有用额外抓地力、假车速或假转速掩盖物理现象。

## 验证

- `tests/power_gearing_test.gd` 的最终 49 项检查均通过，覆盖功率插值上限、净输出、三种驱动轴、低速空转禁止升挡、高转速低车速降挡、超转保护、收油选挡、空中/手刹/手动例外，以及三车型真实泥地运行。
- 真实泥地将车辆设为 25 km/h、6767 RPM、六挡并给予匹配的空转轮速，FWD / AWD / RWD 均在 2 秒内恢复到一或二挡，无复位或修改车速。
- 完整 `regression` 的 23 组测试无失败，全部脚本解析通过，30/60/120 FPS 回放差异低于 1%。完整赛段的模拟量与二值键盘输入均经过全部 31 个检查点且无需恢复；自动控制试跑用时分别约 237.96 / 303.42 秒，最大偏离中心线约 0.47 / 0.58 m。
- 当前平地 AWD 0–80 km/h 为约 6.11 秒，80 km/h 制动距离约 25.86 m；旧里程碑记录保留为历史测量，不代表新动力标定的加速成绩。
- 真实窗口的 3 项检查通过，选车功率说明与倒车 HUD 的截图布局检查通过。真实手柄与新的油门手感仍需人工试玩验收。
