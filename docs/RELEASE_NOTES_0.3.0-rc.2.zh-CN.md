# Art Rally 0.3.0-rc.2

三条赛道第二版与驾驶界面修订。详细说明与游戏实拍见 [赛道第二版更新](ROUTE_V2_UPDATE.zh-CN.md)。

- 每台车的卡片内独立选择标准／+50%／+100% 动力，确认按钮显示实际参赛组合。
- 停稳后按住制动 1 秒挂倒挡；恢复到坡道后保持驻车，踩踏板继续驾驶。
- 修复高地背景地形遮挡道路、晨雾过浓；发车和终点统一使用方格旗。
- 松岭新增至五处飞坡、连续起伏、天然石拱与岩柱。
- 海岸改为下山赛，终点设黄金海岸观景区，包含帆船、观众、遮阳伞和泳装游客。
- 高地改为爬山赛，终点设山顶观景平台。
- 三条赛道增加折返弯、变化路宽、明确的收窄／可小切提示、中段医疗保障车与工作人员。
- 干燥路面扬尘更连续，追尾视角可见。

赛道版本升级为 2。旧成绩和幽灵保留，但不参与新路线排名；已有动力解锁保留。奖牌阈值仍为待真人标定的工程目标。

验证详情见 `docs/validation/v0.3.0-rc.2.json`。常规检查 44 组、884 项及 6 项 Python 工具测试通过；五处飞坡均通过实际腾空落地检查。27 个赛道／车辆／动力组合全部自动完赛且零恢复，81 项回归断言通过。macOS 导出包启动检查通过，Windows 完成交叉导出和结构检查。

这是候选试玩版。真实 Windows、实体手柄、主观听音、真人奖牌标定和单实例全赛段稳定 60 FPS 尚未通过发布验收。短时性能诊断时另一份游戏与编辑器仍在运行，不能据此得出独占运行的性能结论。

macOS 为 Universal ad-hoc 签名包，未进行 Apple 公证；Windows 为未签名 x86_64 包。解压后启动 `Art Rally.app`／`Art Rally.exe`。校验值见 `SHA256SUMS.txt`。
