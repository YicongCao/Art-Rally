## 新玩家流程

- [ ] 不读 README 完成选关、选车、完赛、重试。
- [ ] 教学提示能理解，跳过后能直接挑战。
- [ ] 存档重启后成绩、分段、设置、键位和幽灵正确。
- [ ] 三车灰度与跟车轮廓容易辨认，三主题辨识清晰。
- [ ] 各赛道所有弯道、接缝、路书、恢复点与制动视距自然。
