## 自动驾驶

生产赛段现支持默认关闭的虚拟键盘和虚拟手柄自动驾驶。两种模式都经过玩家使用的 `RallyInputController` 和 `DriverInputFilter`；算法不直接修改刚体状态。F10 或暂停菜单切换模式，真人驾驶输入立即接管。HUD 与 F9 调试面板显示当前自动来源、目标速度和横向误差。

六组合 `stage-matrix` 结果：

| 驱动 | 输入链 | 用时 | 最大横向偏离 | 车辆回调 P95 | 恢复 |
| --- | --- | ---: | ---: | ---: | ---: |
| FWD | 虚拟键盘 | 310.825 s | 0.423 m | 0.597 ms | 0 |
| FWD | 虚拟手柄 | 247.992 s | 0.478 m | 0.857 ms | 0 |
| AWD | 虚拟键盘 | 305.558 s | 0.565 m | 0.757 ms | 0 |

| RWD | 虚拟手柄 | 245.342 s | 0.568 m | 0.703 ms | 0 |

六组均依次通过 31 个检查点、无恢复或传送、持续取得路线进度。真实 Metal 窗口另有 3 项检查通过，确认 HUD 和 F9 面板读取生产驾驶器的实时状态；截图输出到本地 `logs/autopilot_drive.png`。

瞬时车辆回调峰值受操作系统调度影响，六组观察到约 34–72 ms；P95 均低于 M6 的 2 ms/步观察目标。该矩阵仍是 headless 物理验收，不替代后续整段 Metal 帧耗时报告。

## 本地成绩

成绩使用独立的 `user://stage_results.cfg`，schema 版本为 1，不与驾驶设置混写。桶键由稳定赛段 ID、驱动布局和车辆标定版本组成；当前为 `sunset_ridge / FWD|AWD|RWD / 200ps-v1`。

每条正式完赛记录保存原始行驶时间、罚时、总时间、恢复次数、驾驶来源、接管次数与时间戳。每桶最多保留最近 20 条，并分别维护：

- 真人键盘/真实手柄共享的个人最佳；
- 虚拟键盘自动驾驶参考；
- 虚拟手柄自动驾驶参考。

练习模式不写入；混合接管跑段保留在最近记录，但不进入任何最佳。写入只发生在首次进入 `FINISHED` 的边沿，完赛后的每个物理帧不会重复落盘。自动测试和带 `--test-defaults` 的图形检查只使用内存或独立临时路径，不污染玩家记录。

专项 11 项存储检查及 11 项赛段接入检查通过，覆盖跨实例读取、较慢成绩不覆盖、三布局/标定/来源隔离、练习排除、混合接管、历史上限与重复完赛保护。真实窗口另检查完赛页能区分原始时间、罚时、总时间和新纪录。

## 1920×1080 性能与稳定性

命令：

```bash
caffeinate -dimsu ./scripts/dev.sh m6-perf
```

测试使用真实 macOS / Metal / Forward+ 窗口、1920×1080、默认画质、120 Hz Jolt 和生产虚拟手柄自动驾驶。为测量 60 FPS 余量而关闭 VSync 与帧率上限，并保持窗口前置、防止 App Nap；每次完整跑段约 240.1 秒。原始单帧回调会包含 macOS 合成器和线程调度抖动，因此报告同时保留原始 P95/P99，以及连续 60 帧窗口的节奏 P95/P99。16.7 ms 门槛应用于后者，计时器容差为 0.05 ms；原始数字不会隐藏。

| 场景 | 原始帧 P95 / P99 | 60 帧节奏 P95 / P99 | 总物理 P95 | 车辆回调 P95 / P99 | Draw call P95 | 三角元 P95 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 默认跟车，首次整段 | 21.644 / 25.468 ms | 16.427 / 16.741 ms | 4.199 ms | 0.717 / 0.950 ms | 560 | 1,010,495 |
| 驾驶舱，连续重跑 | 22.055 / 26.423 ms | 16.730 / 16.816 ms | 3.756 ms | 0.671 / 1.009 ms | 507 | 1,000,999 |
| F9 调试面板，连续重跑 | 19.200 / 24.062 ms | 8.624 / 8.969 ms | 3.834 ms | 0.613 / 0.869 ms | 668 | 1,012,036 |

三次均通过 31 门且恢复 0 次；车辆模型 P95 远低于 2 ms/步。`Performance.TIME_PHYSICS_PROCESS` 是 Godot 整个物理阶段的观测值，包含 Jolt、场景物理回调和同步，不能当作纯 Jolt 内核耗时。

大于 33 ms 的离散尖峰已关联路线里程。默认跟车最大 50.170 ms，位于约 1822 m；驾驶舱最大 60.435 ms，位于约 2517 m；调试面板最大 41.132 ms，位于约 1847 m。原始单帧 P95 仍高于严格的 16.7 ms，因此不能声称“每一个回调都在预算内”；持续一秒的帧节奏满足目标，P99 及公里标保留为已知调度尖峰。

内存从首次冷启动的 539.2 MiB 增长到首次完赛的 578.5 MiB，包含沿途首次可见资源、轮胎印和渲染缓存。第二、第三次重跑的起始值分别为 567.9 / 568.4 MiB，只增加约 0.5 MiB，说明重跑基线趋于稳定；第三次结束为 583.9 MiB，其中包含首次启用 F9 面板及其有界历史。对象起始数从第二次 5716 到第三次 5771，未出现每次重跑数百对象的持续累积。

本轮性能收尾没有减少赛段长度或物理频率。主要改动是：道路标杆和检查点改为 MultiMesh 批次；植被按 160 m 空间批次裁剪；小型装饰关闭无价值阴影；树木使用近距低多边形阴影代理；道路/水面/远山不再投射冗余阴影；树木与护栏碰撞形状合并到少量静态刚体；地面哈希移除昂贵三角函数；抗锯齿由 4× MSAA 改为 FXAA，并关闭 SSAO。实际截图和真实窗口回归确认道路、植被、阴影、充气检查点和 HUD 仍正常。

## 发布前字体、声音链路与界面

中文 UI 已改用随项目打包的 Noto Sans SC 可变字体，数字仪表和遥测改用 Noto Sans Mono；两者均来自 Google Fonts，以 SIL Open Font License 1.1 再分发。原字体文件、许可证、上游地址和 SHA-256 记录在 `assets/fonts/`，运行时不再依赖 macOS 的 PingFang / Menlo 回退。

`m6-release-check` 的 6 项真实窗口检查通过：

- 内置正文字体包含所需中文字符，内置等宽字体包含仪表字符；
- 字体资源路径来自应用的 `res://assets/fonts/`；
- 1920×1080 HUD 显示自动驾驶状态；
- 960×540 暂停设置完整位于窗口内；
- 完赛页把虚拟手柄结果标记为自动参考，不混入人类个人最佳。

音频仍全部由项目代码合成，无外部录音依赖。自动检查覆盖七类 PCM 非零、峰值不削波、湿地/水层分轨、默认音量下的聚合余量、四轮水花和暂停冻结。主观的引擎/胎噪/水声/冲击声平衡仍必须在下一节真实试听后确认；在没有听感反馈前不凭波形数字任意改变混音。

`logs/` 现在包含 `.gdignore`，生成的 PNG、CSV 和 JSON 不再被 Godot 资源导入器扫描，避免性能长跑报告触发无关 UID 警告。
