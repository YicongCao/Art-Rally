## 开始基线

基线日期：2026-10-15。

- 引擎：Godot 4.7.2 stable，Metal / Forward+，Jolt 120 Hz。
- 分支：`main`，基线提交 `fb3d163`，开始时工作区干净。
- 动力：200 PS，FWD / AWD / RWD 共用车身与动力参数。

开始 M6 前执行：

```bash
./scripts/dev.sh regression
./scripts/dev.sh stage-check
./scripts/dev.sh stage-check --keyboard
./scripts/dev.sh m5-render-check
./scripts/dev.sh drive-choice-render-check
```

结果：

- 完整脚本解析、模型与场景测试通过；30 / 60 / 120 FPS 固定输入回放差异低于 1%。
- 回放基线：5 秒加速距离 51.4203 m、末速度 19.7852 m/s、后续制动距离 21.0357 m。
- 模拟量自动试跑：237.958 s，通过 31 个检查点，恢复 0 次，最大横向偏离 0.469 m，车辆回调 P95 约 0.490 ms。
- 二值键盘辅助自动试跑：303.425 s，通过 31 个检查点，恢复 0 次，最大横向偏离 0.578 m，车辆回调 P95 约 0.510 ms。
- Metal 实际窗口中的合成音频、HUD、驾驶舱、暂停、960×540 菜单布局、选车确认和倒车提示共 9 项检查通过。

车辆回调峰值分别出现约 22.395 ms 和 26.005 ms 的调度尖峰；该值只包围自定义车辆回调，不等于 Jolt 总物理耗时，也不代表整帧或 GPU 性能。M6 后续以 1920×1080 的真实窗口长跑另行记录 P95、P99、卡顿位置和连续重跑内存趋势。

## 自动驾驶

生产赛段现支持默认关闭的虚拟键盘和虚拟手柄自动驾驶。两种模式都经过玩家使用的 `RallyInputController` 和 `DriverInputFilter`；算法不直接修改刚体状态。F10 或暂停菜单切换模式，真人驾驶输入立即接管。HUD 与 F9 调试面板显示当前自动来源、目标速度和横向误差。

六组合 `stage-matrix` 结果：

| FWD | 虚拟键盘 | 310.825 s | 0.423 m | 0.597 ms | 0 |
| FWD | 虚拟手柄 | 247.992 s | 0.478 m | 0.857 ms | 0 |
| AWD | 虚拟键盘 | 305.558 s | 0.565 m | 0.757 ms | 0 |

六组均依次通过 31 个检查点、无恢复或传送、持续取得路线进度。真实 Metal 窗口另有 3 项检查通过，确认 HUD 和 F9 面板读取生产驾驶器的实时状态；截图输出到本地 `logs/autopilot_drive.png`。

瞬时车辆回调峰值受操作系统调度影响，六组观察到约 34–72 ms；P95 均低于 M6 的 2 ms/步观察目标。该矩阵仍是 headless 物理验收，不替代后续整段 Metal 帧耗时报告。

## 本地成绩

成绩使用独立的 `user://stage_results.cfg`，schema 版本为 1，不与驾驶设置混写。桶键由稳定赛段 ID、驱动布局和车辆标定版本组成；当前为 `sunset_ridge / FWD|AWD|RWD / 200ps-v1`。

每条正式完赛记录保存原始行驶时间、罚时、总时间、恢复次数、驾驶来源、接管次数与时间戳。每桶最多保留最近 20 条，并分别维护：

- 真人键盘/真实手柄共享的个人最佳；
- 虚拟键盘自动驾驶参考；
- 虚拟手柄自动驾驶参考。

练习模式不写入；混合接管跑段保留在最近记录，但不进入任何最佳。写入只发生在首次进入 `FINISHED` 的边沿，完赛后的每个物理帧不会重复落盘。自动测试和带 `--test-defaults` 的图形检查只使用内存或独立临时路径，不污染玩家记录。

专项 11 项存储检查及 11 项赛段接入检查通过，覆盖跨实例读取、较慢成绩不覆盖、三布局/标定/来源隔离、练习排除、混合接管、历史上限与重复完赛保护。真实窗口另检查完赛页能区分原始时间、罚时、总时间和新纪录。
