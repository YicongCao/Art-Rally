# M3 + M4 实现与验收记录

日期：2026-10-14。Godot 4.7.2 / Jolt / 120 Hz / Apple M4 Pro。用户已肯定 M1/M2 灰盒与驾驶手感；本阶段以不破坏其柏油基线为前提扩展路面和赛段。

## M3 交付

- 新增独立的柏油、砂石、泥地、草土资源，不用单一摩擦系数概括所有差异：同时调整纵横向刚度、滑动平台与滚阻。未标记的旧测试地面继续使用原柏油行为。
- 每轮按接触点查询基础材质，接触斑内约 0.24 m × 0.18 m 范围混合边界；同车左右轮可以处在不同材质。物理、HUD 与 CSV 共用采样状态。
- 积水是基础路面的覆盖层，有独立深度、边缘过渡、湿态抓地与迎水阻力；水阻施加在对应轮端，单侧入水自然产生偏航。没有流体或胎纹排水模拟。
- 三条纵向射线近似圆形轮胎包络，对窄坎提前建立接触，只产生一份弹簧支撑力。F3 可切换；原实验场默认保留单射线，赛段默认包络。
- 原实验场远端增加 200 m 长砂石/泥地/草土区域与 0.10 m 标称积水区。遥测增加材质 ID、水深和水阻，并导出材质参数快照。

自动制动对比协议：相同车辆、单射线、由轮端动力加速至 15 m/s（54 km/h），收油并全制动，速度低于 0.15 m/s 时记录距离。

| 基础路面 | 当前制动距离 |
| --- | --- |
| 柏油 | 13.46 m |
| 砂石 | 15.44 m |
| 泥地 | 21.30 m |

这是当前参数的回归基线，不是普适路面排序或真实轮胎测量。测试还验证左右分离材质、朝高抓地侧的制动偏航、单侧水阻偏航、对称涉水不持续偏航、草土可通行、材质切换无弹飞、无接触时无水阻，以及水阻不制造能量。

## M4 交付

- 固定定义与种子生成约 3050 m 路线，1527 个横断面、77 个静态碰撞块；全部在发车前生成，不进行行驶中的碰撞流式加载。
- 道路宽度通常 5.6 m，泥地收窄到约 5.1 m。道路、路肩、侧面地形共用同一网格源生成视觉与碰撞。地形粗糙度是真实几何，而不是仅法线纹理。
- 砂石起步及连续弯 → 1150–1650 m 泥地与两处水洼 → 1650–2100 m 柏油弯道 → 上坡砂石及 2650 m 坡顶 → 终点。低洼区域带灰盒涵洞出口标记，不是桥梁系统。
- 主路、路肩与草土用明显颜色和高度区分，两侧设置固定种子路桩/灰盒地标。树林、远山、观众、云层和尘泥水粒子仍留给 M5。
- 3 秒倒计时、起点向前穿越启动计时、31 个顺序门、终点冻结结果、计时/练习切换、重跑、暂停、中文文字路书和危险点预告。
- 恢复到最近已通过检查点之前约 6 m 的道路中心，清理车辆和输入状态；计时模式 +5 秒，练习无罚时。重复同帧恢复不重复计费。路书已消费游标不因倒车/恢复重播。
- 终点后有额外约 140 m 制动平地，完赛失足可安全恢复但不改变最终成绩。结果暂不跨启动持久化，属于 M6 范围。
- 主入口改为赛段；F7 或 `./scripts/dev.sh lab` 保留原测试场，F6 返回赛段。

## 验证结果

`./scripts/dev.sh regression`：全部 GDScript 解析、原环境冒烟、M1/M2 回归、多路面/包络、路线几何、计时/恢复与场景集成检查通过。原柏油 30/60/120 FPS 回放仍为相同结果：加速距离 56.3465 m、末速度 22.7695 m/s、后续停车 26.8932 m。

路线几何测试检查坡度、横断面连续性、非相邻道路间距、中心与左右轮道碰撞，以及每个恢复点四轮下方的支撑；固定种子地标可重复。碰撞射线略偏离精确三角顶点，避免边界归属浮点歧义；完整物理跑段另外覆盖真实接缝通行。

会话测试覆盖逆向过门、跳过门、门宽之外通过、长距离传送、暂停、罚时、重跑、练习切换、重置位置、完赛冻结、完赛跌落恢复和路书不被后续弯道立刻覆盖。

`./scripts/dev.sh stage-check` 完整物理跑段：

自动驾驶只给普通转向、油门、制动命令，不直接设定位置/速度，也不绕过检查点。它用于确认路径与会话可跑通，不属于玩家辅助，不会在正式驾驶中自动转向。P95 仅统计车辆回调，不代表 Jolt 总耗时、GPU 性能或 60 FPS 产品保证；操作系统调度仍有尖峰。

真实 Metal / Forward+ 分别启动并检查起步砂石段、泥地水洼段及柏油段截图，确认道路、水面、车辆与中文 HUD 可见。截图位于 `logs/sunset_ridge_*.png`。新增赛段还未由用户手动完整验收，真实手柄也没有在本轮接入。

## 使用与限制

```bash
./scripts/dev.sh run          # 默认赛段
./scripts/dev.sh lab          # 原物理测试场 + 多路面对比区
./scripts/dev.sh regression   # 模型、场景和帧率检查
./scripts/dev.sh stage-check  # 长距离完整物理验证
godot --path . --script tests/visual_capture.gd --max-fps 60 -- --stage --at=1265
```

运行窗口：F3 接触模式；F4 练习/计时并重开；F5 或手柄 Back 完整重跑；R / 手柄 Y 恢复；F6 赛段；F7 测试场；T 遥测；F8 导出。失焦后按 Enter / Start 恢复。Mac 功能键可能需要 Fn。

目前仍是灰盒。地形走廊仅延伸到道路两侧约 22 m，离开走廊会安全恢复；没有用不可见墙封路。多点包络不能模拟轮胎侧壁、可变形土壤或非簧载轮跳。道路相邻碰撞块共边，粗糙度和坡顶控制在目前模型可处理的尺度。中文字体使用本机 PingFang / Noto 回退，跨平台发布字体仍需 M5/M6 处理。

路书曲率分类是简化规则，不是专业领航员调校；长赛段仍需要玩家检查急弯提示、刹车空间和高速度落地。表面物理、水阻与接触均为工程近似，不宣称真实赛车精确复现。
