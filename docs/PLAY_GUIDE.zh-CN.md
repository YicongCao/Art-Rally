# Art Rally 首个试玩版

首次启动先设置专属车牌，保存后进入主菜单。支持中文、字母和数字等可显示字符，最多 10 个；车牌输入、预览与车辆上的字体一致。已有存档首次使用此功能时只需补设一次，成绩与设置保留。之后可在「设置 → 修改车牌」中更改，应用到选车预览和之后的比赛；前后车牌与驾驶标识均显示该号码。

主菜单选择「开始计时挑战」→ 赛道 → 车辆 →「驶向起点」。全部内容开放，也可先选「驾驶教学」。赛前页通过金、银、铜牌图标与独立时间显示目标。

| 操作 | 键盘默认 | 手柄默认 |
|---|---|---|
| 加速 / 制动 | W / S 或上下方向键 | 右 / 左扳机 |
| 转向 | A / D 或左右方向键 | 左摇杆 |
| 手刹 | 空格 | A |
| 恢复车辆 | R | Y |
| 镜头 | C | X |
| 升 / 降挡 | E / Q | 右 / 左肩键 |
| 暂停 | Esc | Start |
| 重试 | F5 | Back |

键盘映射、自动换挡、幽灵、音量和画面简化在设置中调整。停稳后持续制动可自动挂倒挡。练习模式可在暂停页调整悬架与制动力分配。

正式成绩 = 行驶时间 + 罚时，手动恢复 +5 秒、越界恢复 +10 秒。三个分段与最佳成绩按赛道、车型和规则版本分别保存。同分不覆盖幽灵。练习、F10 自动驾驶以及中途人工接管均不写入玩家纪录。奖牌目前使用暂定阈值，真人标定完成前不是最终难度。

个人最佳幽灵没有碰撞；靠近玩家时淡出，恢复罚时内隐藏。菜单成绩册展示九个挑战进度。退出比赛放弃当前跑段，已完成成绩保留。

声音默认开启，进入「设置」可确认驱动、选择输出设备并播放提示音。若操作系统当前将声音送到蓝牙耳机或显示器，可在此选择实际收听的设备。截图工具的静音不会写入玩家档案。

存档位于 Godot `user://player/`（macOS 通常为 `~/Library/Application Support/Godot/app_userdata/Art Rally/player/`，Windows 为 `%APPDATA%/Godot/app_userdata/Art Rally/player/`）。备份和幽灵一起保留，复制存档请复制整个目录。读取失败不会删除原文件，界面会提示。旧原型成绩单独归档，不参与新挑战。

当前导出包属于开发试玩候选包；须完成真人奖牌标定、主观听音、Windows 和实体手柄验收后才能标为可公开发布。
