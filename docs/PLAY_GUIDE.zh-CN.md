# Art Rally 首个试玩版

首次启动先设置专属车牌，保存后进入主菜单。支持中文、字母和数字等可显示字符，最多 10 个；车牌输入、预览与车辆上的字体一致。已有存档首次使用此功能时只需补设一次，成绩与设置保留。之后可在「设置 → 修改车牌」中更改，应用到选车预览和之后的比赛；号码只出现在车辆牌照上，驾驶 HUD 不重复显示。

主菜单选择「开始计时挑战」→ 选择卡片并「确认赛道」→ 在车辆卡片选择实际马力并确认驾驶→ 加载赛前信息与赛段后自动发车。确认按钮统一在右侧放大，返回按钮在左侧缩小。全部赛道和标准版车辆开放，也可先选「驾驶教学」。加载页通过金、银、铜牌图标与独立时间显示目标。

原厂组任意一次正式金牌解锁三车的进阶马力；进阶组再次获得正式金牌，解锁极限马力。每台车在自己的卡片内选择，按钮直接显示 PS。三车分别为 F160：160 / 240 / 320 PS，R200：200 / 300 / 400 PS，A240：240 / 360 / 480 PS。未解锁项显示矢量锁，选中项使用对勾和底色。练习、自动驾驶与混合接管不能解锁，保存成功才生效。

当前检查点规则为 `time-trial-4`：车身擦过气柱即通过；漏过普通检查点自动加罚 5 秒并继续，无需折返。起点、终点仍需实际穿过，练习模式不累计罚时。旧成绩和幽灵保留归档，不参与新纪录比较；已有动力解锁保留。奖牌目标尚待真人标定。

驾驶 HUD 使用半透明磨砂面板。起终点使用带 ART RALLY 字样、胎纹印迹的黑白格充气拱门，沿途检查点保留气柱与菱形符号；只有当前目标显示悬浮符号。

| 操作 | 键盘默认 | 手柄默认 |
|---|---|---|
| 加速 / 制动 | W / S 或上下方向键 | 右 / 左扳机 |
| 转向 | A / D 或左右方向键 | 左摇杆 |
| 手刹 | 空格 | A |
| 恢复车辆 | R | Y |
| 镜头 | C | X |
| 升 / 降挡 | E / Q | 右 / 左肩键 |
| 暂停 | Esc | Start |
| 重试 | F5 | Back |

键盘映射、自动换挡、幽灵、音量和画面简化在设置中调整。停稳后持续制动 0.6 秒可自动挂倒挡。练习模式可在暂停页调整悬架与制动力分配。

正式成绩 = 行驶时间 + 罚时，手动恢复 +5 秒、越界恢复 +10 秒。三个分段与最佳成绩按赛道、车型、动力档位和规则版本分别保存。同分不覆盖幽灵。练习、F10 自动驾驶以及中途人工接管均不写入玩家纪录。奖牌目前使用暂定阈值，真人标定完成前不是最终难度。

个人最佳幽灵默认开启，仅播放同赛道版本、车型和实际马力规格的有效最快轨迹。个人最佳幽灵没有碰撞；靠近玩家时淡出，恢复罚时内隐藏。菜单成绩册可切换动力档位，分别展示每档九个挑战进度。退出比赛放弃当前跑段，已完成成绩保留。

声音默认开启，进入「设置」可确认驱动、选择输出设备并播放提示音。若操作系统当前将声音送到蓝牙耳机或显示器，可在此选择实际收听的设备。截图工具的静音不会写入玩家档案。

存档位于 Godot `user://player/`（macOS 通常为 `~/Library/Application Support/Godot/app_userdata/Art Rally/player/`，Windows 为 `%APPDATA%/Godot/app_userdata/Art Rally/player/`）。备份和幽灵一起保留，复制存档请复制整个目录。读取失败不会删除原文件，界面会提示。旧原型成绩单独归档，不参与新挑战。

当前导出包属于开发试玩候选包；须完成真人奖牌标定、主观听音、Windows 和实体手柄验收后才能标为可公开发布。

完赛页会自动播放本次轨迹，默认电视跟随镜头。可以暂停、拖动进度或切换航拍、追尾、路旁机位；「沉浸回放」隐藏成绩，控制栏闲置三秒后收起。空格播放／暂停，C 切镜头，左右键跳转五秒，Esc 返回成绩。保存成功的新纪录有简短纸屑礼花。

直升机每场经过四次并航拍，标题页「相册」可查看照片，自动保留最近 64 张。照片和元数据位于玩家目录的 `gallery/`，复制存档时一并复制。标题与三条赛道各有原创主题配乐，设置中的「背景音乐」可独立调整。
