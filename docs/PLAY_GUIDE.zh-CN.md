# Art Rally 首个试玩版

首次启动先设置专属车牌，保存后进入主菜单。支持中文、字母和数字等可显示字符，最多 10 个；车牌输入、预览与车辆上的字体一致。已有存档首次使用此功能时只需补设一次，成绩与设置保留。之后可在「设置 → 修改车牌」中更改，应用到选车预览和之后的比赛；号码只出现在车辆牌照上，驾驶 HUD 不重复显示。

主菜单选择「开始计时挑战」→ 选择卡片并「确认赛道」→ 选择卡片并「确认车辆」→ 加载赛前信息与赛段后自动发车。确认按钮统一在右侧放大，返回按钮在左侧缩小。全部赛道和标准版车辆开放，也可先选「驾驶教学」。加载页通过金、银、铜牌图标与独立时间显示目标。

标准版任意一次正式金牌解锁三车的「动力 +50%」；使用 +50% 版再次获得正式金牌，解锁三车的「动力 +100%」。在选车页上方手动切换档位；未解锁的选项显示解锁条件。三车分别为 F160：160 / 240 / 320 PS，R200：200 / 300 / 400 PS，A240：240 / 360 / 480 PS，质量与驱动形式保持原标定。练习、自动驾驶与混合接管均不能解锁，保存成功才生效。

0.3.0 候选版改进了路肩与草地物理，因此使用新的 `time-trial-2` 规则隔离旧成绩和幽灵；旧成绩仍保留在档案中，旧版有效金牌仍可解锁 +50%。新增动力档位使用独立的暂定奖牌目标，尚待真人标定。

驾驶 HUD 使用半透明磨砂面板。起点为双箭头符号，沿途检查点为菱形符号，终点为方格旗；只有当前目标显示悬浮符号，配对气柱仍提示赛道边界。

| 操作 | 键盘默认 | 手柄默认 |
|---|---|---|
| 加速 / 制动 | W / S 或上下方向键 | 右 / 左扳机 |
| 转向 | A / D 或左右方向键 | 左摇杆 |
| 手刹 | 空格 | A |
| 恢复车辆 | R | Y |
| 镜头 | C | X |
| 升 / 降挡 | E / Q | 右 / 左肩键 |
| 暂停 | Esc | Start |
| 重试 | F5 | Back |

键盘映射、自动换挡、幽灵、音量和画面简化在设置中调整。停稳后持续制动可自动挂倒挡。练习模式可在暂停页调整悬架与制动力分配。

正式成绩 = 行驶时间 + 罚时，手动恢复 +5 秒、越界恢复 +10 秒。三个分段与最佳成绩按赛道、车型、动力档位和规则版本分别保存。同分不覆盖幽灵。练习、F10 自动驾驶以及中途人工接管均不写入玩家纪录。奖牌目前使用暂定阈值，真人标定完成前不是最终难度。

个人最佳幽灵没有碰撞；靠近玩家时淡出，恢复罚时内隐藏。菜单成绩册可切换动力档位，分别展示每档九个挑战进度。退出比赛放弃当前跑段，已完成成绩保留。

声音默认开启，进入「设置」可确认驱动、选择输出设备并播放提示音。若操作系统当前将声音送到蓝牙耳机或显示器，可在此选择实际收听的设备。截图工具的静音不会写入玩家档案。

存档位于 Godot `user://player/`（macOS 通常为 `~/Library/Application Support/Godot/app_userdata/Art Rally/player/`，Windows 为 `%APPDATA%/Godot/app_userdata/Art Rally/player/`）。备份和幽灵一起保留，复制存档请复制整个目录。读取失败不会删除原文件，界面会提示。旧原型成绩单独归档，不参与新挑战。

当前导出包属于开发试玩候选包；须完成真人奖牌标定、主观听音、Windows 和实体手柄验收后才能标为可公开发布。
