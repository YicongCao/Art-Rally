# Brushline Rally 首个试玩版

首次启动先设置专属车牌，保存后进入主菜单。支持中文、字母和数字等可显示字符，最多 10 个；车牌输入、预览与车辆上的字体一致。已有存档首次使用此功能时只需补设一次，成绩与设置保留。之后可在「设置 → 修改车牌」中更改，应用到选车预览和之后的比赛；号码只出现在车辆牌照上，驾驶 HUD 不重复显示。

主菜单选择「开始计时挑战」→ 选择卡片并「确认赛道」→ 在车辆卡片选择实际马力并确认驾驶→ 加载赛前信息与赛段后自动发车。确认按钮统一在右侧放大，返回按钮在左侧缩小。全部赛道和标准版车辆开放，也可先选「驾驶教学」。加载页通过金、银、铜牌图标与独立时间显示目标。

原厂组任意一次正式金牌解锁三车的进阶马力；进阶组再次获得正式金牌，解锁极限马力。每台车在自己的卡片内选择，按钮直接显示 PS。三车分别为 F160：220 / 330 / 440 PS，R200：240 / 360 / 480 PS，A240：288 / 432 / 576 PS。未解锁项显示矢量锁，选中项使用对勾和底色。练习、自动驾驶与混合接管不能解锁，保存成功才生效。

当前检查点规则为 `time-trial-4`：车身进入两侧检查点标记之间的判定范围即通过；漏过普通检查点自动加罚 5 秒并继续，无需折返。起点、终点仍需实际穿过，练习模式不累计罚时。旧成绩和幽灵保留归档，不参与新纪录比较；已有动力解锁保留。奖牌目标尚待真人标定。

驾驶 HUD 使用半透明磨砂面板。起终点使用带 BRUSHLINE RALLY 字样、胎纹印迹的黑白格充气拱门，沿途检查点使用成对光柱：松岭冰青、海岸兰紫、高地琥珀金。当前目标最亮并显示菱形符号，后续光柱较暗，通过后进一步淡出。

| 操作 | 键盘默认 | 手柄默认 |
|---|---|---|
| 加速 / 制动 | W / S 或上下方向键 | 右 / 左扳机 |
| 转向 | A / D 或左右方向键 | 左摇杆 |
| 手刹 | 空格 | A |
| 恢复车辆 | R | Y |
| 镜头 | C | X |
| 升 / 降挡 | E / Q | 右 / 左肩键 |
| 暂停 | Esc | Start |
| 重试 | F5 | Back |

键盘映射、自动换挡、幽灵、音量和画面简化在设置中调整。停稳后持续制动 0.6 秒可自动挂倒挡。练习模式可在暂停页调整悬架与制动力分配。

正式成绩 = 行驶时间 + 罚时，手动恢复 +5 秒、越界恢复 +10 秒。三个分段与最佳成绩按赛道、车型、动力档位和规则版本分别保存。同分不覆盖幽灵。练习、F10 自动驾驶以及中途人工接管均不写入玩家纪录。奖牌目前使用暂定阈值，真人标定完成前不是最终难度。

个人最佳幽灵默认开启，仅播放同赛道版本、车型和实际马力规格的有效最快轨迹。个人最佳幽灵没有碰撞；靠近玩家时淡出，恢复罚时内隐藏。菜单成绩册可切换动力档位，分别展示每档九个挑战进度。退出比赛放弃当前跑段，已完成成绩保留。

声音默认开启，进入「设置」可确认驱动、选择输出设备并播放提示音。若操作系统当前将声音送到蓝牙耳机或显示器，可在此选择实际收听的设备。截图工具的静音不会写入玩家档案。

存档位于 Godot `user://player/`（macOS 通常为 `~/Library/Application Support/Godot/app_userdata/Brushline Rally/player/`，Windows 为 `%APPDATA%/Godot/app_userdata/Brushline Rally/player/`）。备份和幽灵一起保留，复制存档请复制整个目录。读取失败不会删除原文件，界面会提示。旧原型成绩单独归档，不参与新挑战。

0.5.0 包已完成自动验证；真人奖牌标定、真实 Windows 和实体手柄验收仍未完成。macOS 使用 ad-hoc 签名，未进行 Apple 公证。

完赛页会自动播放本次轨迹，默认电视跟随镜头。可以暂停、拖动进度或切换航拍、追尾、路旁机位；「沉浸回放」隐藏成绩，控制栏闲置三秒后收起。空格播放／暂停，C 切镜头，左右键跳转五秒，Esc 返回成绩。保存成功的新纪录有简短纸屑礼花。

直升机每场经过四次并航拍，标题页「相册」可查看照片，自动保留最近 64 张。照片和元数据位于玩家目录的 `gallery/`，复制存档时一并复制。标题与三条赛道各有原创主题配乐，设置中的「背景音乐」可独立调整。

手柄右摇杆可环视和调整俯仰，松开后保留角度，按下右摇杆（R3）回正。此操作不会改变油门、转向或自动驾驶状态。

## Brushline 开发验证版

松岭正式真人挑战任一车辆／已解锁动力档金牌，同时开放海岸与高地；自由练习始终可进入所有赛道。旧版有效成绩保留已有入口。首次新品牌启动会复制并校验旧 Art Rally 档案及备份、设置、幽灵和相册，旧目录保持完整。高地暮色／悬崖碰撞升级至赛道版本 8，旧高地成绩保留在档案但不参与新成绩比较。

标题页「玩法演示」自动驾驶约两分钟，三个章节依次使用追尾、轮胎侧面和电视跟拍。左侧为真实轮胎和动力遥测；Esc 可暂停／退出。结束可重播并查看固定场景性能。演示不授予奖牌、不保存个人幽灵或航拍照片。设置的「减少动态效果」会把漫画插页改为短淡入。


## 0.5.0 菜单与演示

标题主行的「玩法演示」播放 75 秒三赛道、三辆车的实机精选。两侧精简 HUD 显示真实车速、转速、挡位、侧滑角、轨迹计算的横纵 G，以及原厂全油门扭矩曲线（并非当时实际输出扭矩）。空格 / Esc / 手柄 Start 暂停。结束后显示本轮实播 FPS 曲线和平均、最高、最低值；加载与暂停不计入，重播清空统计。

操作指南提供透明矢量手柄图和稀疏键盘布局；键盘显示当前映射，鼠标用于菜单选择。手动 / 自动换挡可用 M 切换。成绩册按三条赛道并排展示，一屏可查看九个成绩并找到返回主菜单按钮。
