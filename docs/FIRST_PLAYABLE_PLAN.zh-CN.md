# Art Rally 首个完整试玩版实施计划

用户确认：2026-10-18。目标为完全离线、可公开试玩的精品计时拉力游戏。保留 Godot 4.7.2、Jolt、现有车辆物理和轮胎系统，重点投入流程、内容、视听和玩家体验。

## 1. 首版范围

- 三条主题赛道、三辆原创复古赛车，组成九个独立计时挑战，全部初始开放。
- 每挑战提供铜银金奖牌、三个计时分段、个人最佳及个人幽灵车。
- 完整主菜单、选关、选车、加载/赛前介绍、驾驶、成绩页、重试/换车/返回选关；另有练习、可跳过/重玩的短教学、成绩册、设置、制作名单、退出。
- 完整本地存档、驾驶/环境/界面声音及菜单/成绩页音乐，路书采用提示音配文字。
- macOS 和 Windows 桌面包；对应平台实机验收通过后才能标记可发布。
- 不增加经济、生涯、联网、开放世界、动态天气、复杂车损、中文语音领航或涂装编辑器。

## 2. 赛道

### 夕照松岭 / 约 3.05 km
保留现有砂石、泥地、柏油组合及路线，作为入门综合赛段。金色草坡、橙红树冠、青绿松树、桃粉天空。强化起终点、排水涵洞、林间空地、坡顶辨识度。驾驶重点是路面差异、入弯速度及连续弯道。

### 晴岬海岸 / 约 2.8 km
柏油为主，中高速沿海弯、连续爬坡及三组明确发夹弯。青蓝海面、乳白岩壁、暖白天空、少量深绿植被，以灯塔为主地标。强调制动点、走线、出弯加速；海面仅为景观，可见护栏与合理恢复区域保护沿海道路。

### 雾杉高地 / 约 3.2 km
砂石为主，局部泥地及浅积水，高速缓弯、连续起伏及较窄林间路。蓝灰山石、墨绿针叶林、浅黄草甸、低处薄雾，山口石阵和溪沟涵洞为地标。强调节奏、起伏及低抓地出弯。雾不可遮蔽必要制动距离，不增加冰雪或实时降雨。

三赛道均为手工路线、固定装饰种子、固定光照，复用基础资产但分别制作地标与环境配色。

## 3. 三辆车

初始标定目标在驾驶验证后冻结，不重写物理求解器。

- **F160 / 前驱 / 160 PS / 1000 kg / 轴距 2.35 m**：短车头、高车顶、直立尾门、窄轮拱、小车顶扰流板。奶油白车身、青绿车顶及下侧围、粗斜切色块、16 号；方形前灯、竖向尾灯、白轮毂。轻快易理解。
- **R200 / 后驱 / 200 PS / 1100 kg / 轴距 2.50 m**：长车头、低车顶、后移座舱、溜背、鸭尾。朱红车身、贯穿车头/车顶/尾部的奶油白双纵条纹、27 号；双圆前灯、细横尾灯、深灰轮毂。强调渐进油门与车尾控制。
- **A240 / 四驱 / 240 PS / 1300 kg / 轴距 2.60 m**：方正四门、外扩轮拱、宽轮距、高尾翼、车头进气。深钴蓝车身、金黄腰线及尾翼端板、白底 44 号；矩形前灯、宽横尾灯、金轮毂。出弯牵引强，需要提前制动。

使用 Blender 原创低多边形模型，保存可编辑源文件及 GLB。适量倒角、统一材质、大色块、原创号码；不用真实品牌或赞助商。灰度及跟车视角仍能通过轮廓辨识。复用轮胎形变、转向、刹车灯、仪表，独立配置碰撞、轮系及镜头挂点；三车拥有不同简化驾驶舱轮廓和饰色。

## 4. 内容与流程接口

- StageDefinition：赛道版本、环境、路面区间、宽度、积水、起伏、危险路书、地标及分段点；移除松岭距离硬编码。
- VehicleDefinition：稳定车型 ID、车辆/传动参数、模型、涂装、碰撞、镜头与音色。
- ChallengeDefinition：赛道、车型、规则版本和奖牌目标；菜单与比赛共用内容目录。
- 正式游戏流程与开发测试场分离，保留遥测、测试场和自动驾驶。
- 加载显示实际阶段进度，必要碰撞/资源全部就绪才发车；切场景释放旧资源与声音。
- 教学复用松岭起段，包含加速制动、转弯、路书、恢复和成绩目标。
- 成绩页显示原始时间、罚时、总成绩、分段、个人最佳差距、奖牌及下一级差距；成绩册展示九格奖牌，全部铜牌完成基础挑战，全部金牌额外反馈。

## 5. 挑战与幽灵

- 最终成绩为行驶时间加罚时，按赛道、车型及版本隔离；保留检查点与恢复规则。
- 正式挑战固定机械调校，允许输入辅助与自动换挡；机械调校只用于练习。
- 练习、自动驾驶、混合接管不授奖牌，不覆盖玩家最佳/幽灵。
- 每组合至少三次熟练真人无恢复基准跑，以最快有效时间 T 的 105%/120%/140% 向上取整为金/银/铜初值；试玩后冻结目标及挑战版本，不动态随玩家变更。没有真人跑段时，明确标记临时目标，不能声称已标定。
- 幽灵 30 Hz 记录真实姿态/车轮，插值播放，不重新运行物理，不依赖输入回放确定性。使用含罚时挑战时钟；恢复显式分段，罚时区间隐藏，不跨重置插值。
- 幽灵无碰撞、声音和粒子，半透明，近车/重叠淡出，可关闭。每挑战仅保存有效最佳；新纪录保存成功后替换旧记录；不兼容版本不播放。

## 6. 本地存档

单一本地档案保存设置、按键、教学、最近选择、奖牌、最佳/分段/近期记录、幽灵引用。版本化、临时文件替换、有效备份，成绩与幽灵保持一致。损坏尝试备份，读写失败可见提示，不静默删除。迁移旧设置，旧原型成绩归档，不混入新车。退出比赛放弃当前跑段，不保存中途状态。

## 7. 音频

先检查正常启动和导出包的设备、驱动、暂停、音量与调用链，不能把存在 PCM 波形当作听感验收。设置页提供试听和独立音量；首次非静音，尊重已存静音设置；截图静音仅影响测试会话。

- 三车独立怠速、低中高转、负载、收油，增加换挡、传动、制动反馈，不能仅同一声音变调。
- 柏油/滑胎、砂石、泥地、入水、悬架落地、车身接触（真实事件驱动及防连续误触发）。
- 松岭林风鸟鸣、海岬海浪海风、高地山风溪流，空间定位及衰减。
- 菜单、发车、路书、危险、完赛、奖牌、新纪录反馈。
- 菜单/成绩页轻量原创循环音乐，驾驶默认以车辆、环境和提示为主。
- 分层混音，提示压低背景，暂停冻结循环，恢复平滑。

免费可分发 CC0 素材优先，界面音可选 Kenney Interface Sounds：https://kenney.nl/assets/interface-sounds 。缺口用原创程序合成，记录来源、许可与生成脚本，全部离线打包。

## 8. 实施与验收

1. 内容接口、游戏入口、音频恢复，先贯通松岭的启动/暂停/结束/返回。
2. 松岭端到端挑战：奖牌、分段、成绩、存档、幽灵，验证重启后查看与竞赛。
3. 三车三赛道及九挑战、独立路书/恢复、教学。
4. 完整视听、真人试玩/奖牌标定、迁移、硬件验收、发布包/校验值/说明/素材名单。

自动验证覆盖奖牌边界、罚时、分段、同分、各驾驶来源/版本隔离，存档损坏/迁移/失败，新纪录与幽灵版本/恢复/暂停。九组合自动回归及真人完整跑段；检查道路缝隙、恢复、镜头与模型。耳机、扬声器、导出包实际试听。M5 1080p60 为性能目标，记录完整跑段帧耗时与物理开销，十次切场景无持续资源增长。Windows、真实手柄、真人和主观听感未实测时明确待验收，不以模拟替代。
