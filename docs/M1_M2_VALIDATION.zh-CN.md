# M1 + M2 实现与验收记录

日期：2026-10-14。基线环境：Godot 4.7.2、Jolt、120 Hz、Apple M4 Pro、macOS。代码和自动测试已经落地；真实手柄校准与主观驾驶品质未宣称验收完成。

## 已实现

- M1 测试场：直线制动、25 m 定圆、蛇形、单个减速带、连续起伏和坡顶跳跃；视觉与碰撞共用几何参数。
- M1 输入：手柄标准映射与动态设备选择、标准/轻辅助键盘配置、渐进踏板和转向、高速限制、快速反打；失焦/断开暂停，明确恢复，设备切换不遗留输入。
- M1 车辆：独立质量/重心/惯量参数、四轮射线接触、弹簧与压缩/回弹阻尼、渐进触底、车体碰撞、轮端驱动、跟车/引擎盖视角和安全重置。
- M2 轮胎：连续峰值与峰后滑动曲线、载荷敏感性、组合摩擦圆（摩擦椭圆的等轴特例）、松弛响应、隐式低速轮速/接触求解。车轮离地清除接触与松弛力。
- M2 悬架/传动：前后防倾杆、约 230 kW 起始转矩曲线、发动机惯性、自动离合、六挡/N/R、自动/手动换挡、切断换挡转矩、发动机制动、有限锁止的前后/中央差速器以及手刹中央解耦近似。
- 工具：20 Hz 开发 HUD、接触法向与轮胎力绘制、物理步输入命令、最多 120 秒有界遥测缓存、CSV 和引擎/车辆/轮胎/传动参数快照。

## 自动验证

执行 `./scripts/dev.sh regression`。它包括资源导入、每个 GDScript 的独立解析检查、原环境冒烟测试，以及以下测试组。任何解析错误或测试断言失败都返回非零退出码。

| 测试组 | 覆盖 |
| --- | --- |
| 输入 | 时间一致性、死区、全量程、高速限制、反打、单次换挡事件、跨设备清理、失焦/断开、非法数值 |
| 轮胎与防倾杆 | 空中无抓地、组合力上限、低速稳定、峰后曲线、载荷敏感性、松弛、左右对称、载荷守恒、正反车速/轮速/载荷组合扫描 |
| 动力总成 | 发动机与离合起步、换挡中断/间隔、自动升挡、限转、危险降挡阻止、有限限滑、转矩守恒、差速耗散、手刹解耦和发动机制动 |
| 基础车辆 | 静态轮荷误差低于 5%、静态高度、10 秒漂移小于 0.1 m、离地落地、直线对称性、制动停车、倒车与转弯 |
| 动态车辆 | 80 km/h 制动、俯仰、定圆、外侧载荷、手刹、蛇形、仅二值键盘输入的辅助蛇形、滑行耗散、单轮越坎、连续起伏、坡顶离地落地和翻车重置 |
| 场景/遥测 | 测试场碰撞、暂停与恢复、已暂停时失焦不意外恢复、CSV 列数、有限保留窗口、循环缓冲按时间顺序导出 |
| 渲染步长 | 同一物理步输入在虚拟 30/60/120 FPS 下的加速速度/距离和制动距离偏差低于 1% |

本次记录的动态基线：

| 指标 | 本次值 |
| --- | --- |
| 0–80 km/h | 4.85 s |
| 80 km/h 全制动距离 | 26.02 m |
| 制动最大俯仰 | 2.29° |
| 25 m 目标定圆实际半径 | 26.15 m |
| 定圆速度 / 侧倾 | 8.02 m/s / 1.29° |
| 单轮越坎左右行程差峰值 | 0.110 m |
| 二值键盘控制低速蛇形 | 30 秒内至少 4 次横向目标切换，姿态有界 |

30/60/120 FPS 的同条件回放均得到：5 秒加速距离 56.3465 m、末速度 22.7695 m/s、后续停车距离 26.8932 m。此协议与“达到恰好 80 km/h 后刹车”的动态测试不同，所以停车距离不完全相同。这验证同环境下的时间解耦，不保证跨平台刚体确定性。

最新机器可读报告在忽略版本控制的 `logs/dynamics_metrics.json` 与 `logs/frame_rate_metrics.json`，日志同时保留通过/失败项。车辆回调 P95 计时仅是开发观察，不包含全部 Jolt 求解、遥测和图形工作，不能代替整段 60 FPS 验收。

## 图形验证与试玩

使用真实 Metal / Forward+ 启动测试场并检查截图；确认车身、轮胎、地面、标记、HUD 与天空正常显示，启动和退出无引擎错误。截图工具命令：

```bash
godot --path . --script tests/visual_capture.gd --max-fps 60
```

输出到 `logs/driving_lab.png`。这不是实际用户驾驶反馈。键盘蛇形由二值命令自动驱动，用于验证输入链可完成操作；真实玩家的易用性仍需试玩。

建议人工验收顺序：W 起步/S 制动 → A/D 低速绕桩 → F2 比较辅助 → Q 经空挡进倒挡 → Space 手刹 → R 重置 → 手柄扳机/左摇杆 → 拔掉手柄和切换窗口 → F8 导出。M 切换自动/手动挡；若丢焦后车辆不动，按 Enter 或手柄 Start 恢复。

## 已知限制与后续

- 当前只有柏油模型，路面 ID、水深与草土阻力在 M3 接入；没有通过不同输入设备修改抓地参数。
- 射线只处理悬架方向的接触，没有轮胎侧壁碰撞、真实非簧载质量、完整悬架几何；M3 扩展接触包络。
- 4 个内部子步只耦合轮速/轮胎/传动，车身与接触依然为 120 Hz；每轮使用四分之一车重近似低速有效质量。发动机和车轮转动惯性没有完整映射为空中车身反作用，不能声称满足全系统角动量模型。
- 自动离合与手刹中央解耦是经验近似。手刹时前轴接收传动输出、后轴仅保留其轴内锁止与制动，不模拟实际赛车所有传动机构。
- 轮胎数据是工程起始参数，不来自真实轮胎台架；没有轮胎温度、磨损、胎压、外倾推力与气动下压力。灰盒尚无声音、尘土或正式中文 UI，属于 M5 范围。
- 手柄型号未指定、未接入真实硬件。模拟事件测试验证适配逻辑，不能替代扳机量程/死区/实际手感校准。性能与驾驶趋势通过自动检查，不等于复刻《DiRT Rally 2.0》的精确动力学。
