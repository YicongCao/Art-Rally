# Art Rally 交互与视觉

- 驾驶中的持续状态优先使用 SVG 或程序矢量图形；用轮胎滑移、手刹、换挡等图标表达状态，给图标固定位置，不能与时速、挡位、转速重叠。紧急信息可保留简短文字；说明放在操作指南或提示中。
- 使用矢量勾选、锁定、返回、播放等符号搭配简短文案。不要用 Unicode 圆点、emoji 或长段说明代替图标及布局。
- 选择控件靠近其作用对象。车辆卡片内放自己的动力选择，并显示实际 PS；最终确认按钮复述实际车型和马力。
- 选中态必须持久可见，不能依赖鼠标悬浮或焦点。组合使用矢量对勾、填色和边框；同时区分选中、悬浮、键盘焦点和禁用状态，保证灰度下可辨。
- 确认动作较大、位于右侧；返回动作较小、位于左侧。常用操作优先，说明和次要功能减少视觉权重。
- 车牌输入、预览与车尾显示共用同一字体链，保留中文回退与 10 字符限制。
- 在实际 Godot 渲染中检查 1280×720 和桌面常用比例，验证长车牌、锁定状态、手柄／键盘焦点、回放控件与 HUD 遮挡；截图脚本使用独立档案。

- 普通页面切换使用约 200 ms 的横向侧滑，确认／下一页从右进入，返回从左进入；同页选择不触发整页动画。加载到驾驶使用约 820 ms 的对角线布旗遮罩（340 ms 减速入场、180 ms 停留、300 ms 加速离场），在完全遮盖时切换并播放短音效；停留时布面继续随风起伏，中央使用 ART RALLY 标识、上下使用暖白与深青灰方格，避免纯黑与硬质高光；驾驶返回菜单先黑屏再显示。动画期间阻止重复操作，结束后恢复焦点与操控。

- 设置项按驾驶、画面、声音、机械调校分类；标题与暂停页复用同一组控件，分类导航带矢量图标和持续选中态。驾驶提示只在停稳时显示，状态通知短闪后停留再淡出；回放不得自动左右换边。
