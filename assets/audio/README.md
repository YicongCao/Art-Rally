# Art Rally audio

Effects and instrumental music are original procedural material created for Art Rally. Mandarin co-driver speech is rendered with Apache-2.0 Kokoro; see `voice/LICENSE-Kokoro.txt` and `docs/ASSET_CREDITS.md`.
No external recordings, real vehicle samples, branded audio, online service or runtime download is used.

- `first_playable/*.wav`: generated by `scripts/generate_audio.py` (Python standard library, fixed seed).
- F160 / R200 / A240: five distinct pulse/harmonic layers per car, including idle, low/mid/high load and overrun.
- Three environment loops, interface / start / pacenote / hazard / finish / medal / record / shift / brake / collision cues.
- `menu_music.wav`: original eight-bar pentatonic plucked-keyboard loop.
- `scripts/presentation/synth_audio.gd`: original tire/surface/impact synthesis retained from the prototype.

Effects/music WAV files are mono 16-bit, 22,050 Hz; voice clips use 24,000 Hz, bundled offline. Looping is configured by `RallyAudioDirector.asset`.
Generated originals are part of this project's assets; redistribution follows the project's owner's distribution terms.
No Kenney asset has been downloaded or included. Listening tests on headphones and speakers remain a release gate.

- `generate_world_audio.py`: rotor / river / hoof loops.
- `generate_pacenotes.py`: two offline Mandarin voices; generated WAV only at runtime.
- Music styles: forest garage rock (144 BPM), coast electro house (128 BPM), highland cinematic drums/horns (110 BPM). MIDI and PCM share the authored arrangements.
