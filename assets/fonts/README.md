# Bundled fonts

The release UI embeds two variable fonts so Chinese text and numeric readouts do not depend on fonts installed on the host Mac.

- `NotoSansSC-Variable.ttf` — Noto Sans SC, downloaded from the Google Fonts repository.
- `NotoSansMono-Variable.ttf` — Noto Sans Mono, downloaded from the Google Fonts repository.

Both fonts are distributed under the SIL Open Font License 1.1. The corresponding unmodified license texts are stored as `OFL-NotoSansSC.txt` and `OFL-NotoSansMono.txt`.

Upstream:

- <https://github.com/google/fonts/tree/main/ofl/notosanssc>
- <https://github.com/google/fonts/tree/main/ofl/notosansmono>
